The actual implementation of the behavior of the Controller is done using three coordinated State Machines:

•the "Operation" State Machine.

•the "Security" State Machine.

•the Yawing control.

The Yawing control is an slave of the other two and is implemented using an integrator.

The Operation and Security State Machines are described next sections.
