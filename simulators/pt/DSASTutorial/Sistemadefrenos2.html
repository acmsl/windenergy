Simulação do sensor de vibração da torre

A torre tem um sensor de vibração. É um tipo de 'pendulum', ou seja, dá uma saída digital que se torna ativa quando a massa do pêndulo toca um anel que define o limite máximo tolerado para oscilações.

Este sinal é simulado pelo botão marcado'Tower Vibrations '.

O Controller só leva em conta quando este sinal permanece 'ativo' pelo menos o tempo especificado neste parâmetro. No caso do simulador, este parâmetro é definido como 2 segundos.

Quando este sinal é ativado e permanece ativo por um determinado tempo, o controlador inicia uma parada imediata, mesmo usando o freio hidráulico.
