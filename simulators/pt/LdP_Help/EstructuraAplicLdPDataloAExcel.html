Exportando dados para o Excel

Estrutura das aplicações LdP ›› Registo do valor do sinal (logagem de dados) ››

A aplicação de área de trabalho SQLiteAdministrator (http://sqliteadmin.orbmu2k.de/) tem uma opção para exportar dados de arquivo SQlite para o Excel.


O plugin Firefox "SQLite Manager" também permite exportar os resultados de uma consulta para um arquivo CSV (Comma Separated Values).

Esses arquivos podem ser importados para pastas de trabalho do Excel. As versões mais recentes do Excel incluem um formato que exibe corretamente o formato de data com resolução milissegundo.
