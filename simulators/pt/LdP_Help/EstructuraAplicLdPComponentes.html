Componentes básicos

Estrutura das aplicações LdP ›› Conceitos básicos ››

Uma aplicação LdP (Simulador) é definida por uma descrição em um arquivo de configuração, em que:

• Cada um dos componentes utilizados no Simulador é declarado.

• São declaradas as ligações entre a saída e os sinais de entrada de cada um dos componentes.

•Elementos auxiliares são definidos: valores de parâmetros, ajuda, definição de configurações de gravador gráfico, etc.

Os "componentes" de uma configuração LdP podem ser dos seguintes tipos:

Processos

Este elemento pode conter nenhum, um ou mais "Processo" elementos tipo. Cada um destes refere-se a um DLL desenvolvido especificamente para simular um determinado aspecto ou subsistema.

Sinópticos

Este elemento pode conter um ou mais elementos do tipo "Synoptic". Estes elementos referem-se a DLLs desenvolvidos especificamente usando indicadores gráficos. Eles constituem a interface do usuário.

Ligações

Este elemento contém "Ligação Interna" elementos tipo. Estes elementos contêm um "sinal de saída" e um ou mais "sinais de entrada".

Parâmetros

Este elemento não contém nenhum, um ou mais elementos do tipo "Parâmetro". Cada um deles tem um "sinal de saída" associado com um nome associado a um Processo ou Sinóptico. Existe uma base Synoptic ("Parameters") que permite acessar estes "Parameters" e alterar o valor associado. Geralmente é usado para definir parâmetros de algoritmos implementados nos diferentes elementos "Processo" e "Synoptic".

Gravadores de Tiras

(Gravadores) Este elemento contém um conjunto de "Painel"elementos tipo, cada um dos quais define o conteúdo e formato de "Gravadores," através do qual o conjunto de sinais apresentados e a forma de representação são definidos.

Funções

Elemento contendo nenhum, um ou mais "Função" elementos tipo. Cada um destes elementos implementa um "fórmula": cada fórmula tem um sinal de saída associado e um conjunto de sinais de entrada correspondentes às variáveis que usa.
