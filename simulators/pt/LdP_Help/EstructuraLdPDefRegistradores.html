Descrição dos elementos associados com StripGravers

Gravadores de Tiras

Este elemento tem duas "propriedades" ou "atributos"

Propriedade

Designação das mercadorias

backColor

Esta propriedade determina a cor de fundo dos painéis. As formas possíveis de especificar esta cor são as seguintes:

="0" : cor de fundo preta.

="1" : cor de fundo branca.

="R,G,B" , onde R, G, e B são valores inteiros entre 0 e 255.

Exemplo: "200,200,200" produz a seguinte cor de fundo.

borda Cor

="0" (utilização futura).

Painel

Este elemento tem duas propriedades, "nome"e"descrição," ambos são texto. Cada painel corresponde a uma sinóptica. Pode conter um ou mais "Gravador" elementos.

Gravador

Este elemento pode conter um ou mais "Sinal"elementos e zero, um, ou mais"MarkLine" elementos. Tem as seguintes propriedades:

Propriedade

Designação das mercadorias

tipo

Necessário. Pode ser "A" se você quiser representar sinais analógicos, ou "D" se forem digitais.

nome

Necessário. Usado para identificação.

maxValue

Necessário. Valor superior do eixo vertical dos valores.

minValue

Necessário. Valor inferior do eixo vertical.

altura

Necessário. Altura do gravador em pixels.

escalaMode

Opcional. Os valores podem ser "lin" ou "log". O valor padrão é "lin".

Se "lin", a escala de valor do sinal é linear.

Se "log", a escala de valor do sinal é logarítmica.

Sinal

Este elemento especifica um dos sinais a serem representados no elemento "Recorder" dentro do qual é definido. A cor pode ser escolhida.

Propriedade

Designação das mercadorias

tipo

Necessário. Pode ser "A" se você quiser representar sinais analógicos, ou "D" se forem digitais.

nome

Necessário. Deve corresponder ao nome de um "sinal" válido. VerSinóptico para editar sinais e conexões.

cor

Necessário. ="R,G,B", onde R, G e B são valores inteiros entre 0 e 255.

MarkLine

Este elemento exibe uma linha horizontal correspondente a um possível valor dos sinais representados no elemento "Gravador" onde está definido. A cor e a transparência podem ser alteradas. O texto associado é exibido à direita do eixo de coordenadas.

Propriedade

Designação das mercadorias

valor

Necessário. Valor associado. Exemplos: "10.0", "-15.0", "1e-4", "-2e+8".

etiqueta

Necessário. Texto exibido à direita do eixo y.

cor

Necessário. ="R,G,B", onde R, G e B são valores inteiros entre 0 e 255.

alfa Valor

Necessário. Valor entre 0 e 255 correspondente ao grau de transparência da linha horizontal traçada. 0 é completamente transparente. 255 não é transparente.
