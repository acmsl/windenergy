Estrutura das bases de dados de registos

Estrutura das aplicações LdP ›› Registo do valor do sinal (logagem de dados) ››

A estrutura das bases de dados utilizadas para registar a evolução dos sinais numa simulação é a seguinte:

•Eles estão contidos em um único arquivo criado com o motor de banco de dados SQLite 3.6 .

• Ali.é uma tabela para cada sinal, seja "saída" ou "entrada".

•Cada tabela contém dois campos que dependem do tipo de sinal (analógico ou digital). Um destes campos ("Data") é comum. Veja os seguintes detalhes:

oParasinais analógicos, os campos são:


Nome do campo

Tipo de campo

Designação das mercadorias

Data

Numérico (duplo)

Instantânea de mudança ou amostra com resolução de milissegundo.

ValorA

Numérico(solteiro)

Valor do sinal associado no momento da data


oParasinais digitais, os campos são:


Nome do campo

Tipo de campo

Designação das mercadorias

Data

Numérico (duplo)

Instantânea de mudança ou amostra com resolução de milissegundo.

ValorD

Booleano

Valor do sinal associado no momento da data


Os valores no "Data" campo corresponde à data e hora com resolução milissegundo. A fórmula de conversão é a seguinte:

Instant = (DateFieldValue)/86400000 - 693593
