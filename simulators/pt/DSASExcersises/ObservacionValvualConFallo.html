Observação do efeito de uma válvula de descompressão

Aulas práticas ›› Monitorização do circuito de freio hidráulico ››

O objetivo desta prática é observar o protocolo utilizado pelo controlador quando uma válvula no circuito de freio falha.

Neste caso, utilizaremos uma das características dos indicadores gráficos do framework LdP em que este simulador é desenvolvido. Vamos simular o controle manual diretamente de uma das válvulas de freio.

Para isso, colocaremos a turbina eólica em produção (ver, por exemplo, o exercício práticoDefinição das condições de entrada em produção com vento baixo).

Em seguida, vamos 'selecionar' o«Trava suave 'indicador no "SinopticDriveTrain" synoptic clicando nele. (Nada deve acontecer, como o modo padrão para este indicador é'display only ': sua fronteira é verde).

Pressione a tecla 'F6', e sua borda mudará para vermelho, indicando que agora ela se comporta como um botão com o qual podemos controlar o sinal associado, que é o controle da válvula de freio normal.

Agora clique neste botão com o mouse, e o sinal associado ficará ativo e será indicado no botão, o que mudará sua cor de fundo para amarelo. O trem de energia vai parar imediatamente, e o Controlador irá criar um incidente com a descrição "Bypass ou Thyristors ligado e freio não liberado." Este incidente indica que, durante o processo de travagem (que foi completamente inesperado), houve um intervalo de tempo (alguns milissegundos) em que os Contatores Bypass Thyristor foram ligados e o freio foi ativado. Esta é uma situação perigosa para os componentes eléctricos.
