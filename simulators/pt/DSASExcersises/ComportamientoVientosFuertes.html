Comportamento em ventos muito fortes

Aulas práticas ››

Este exercício prático envolve experimentar o comportamento em resposta aos valores do vento, de acordo com a descrição dos ventos emValores funcionais do vento. 

Na práticaCabo de alimentação para desbobinar,a influência dos valores do vento "Mín. para orientação"e"Mín. para arranque" é observado. Nesta prática, propomos observar a influência dos valores de vento "Máx. para arranque," "Max para operação contínua," "Máximo para operação temporária," e "Máximo absoluto", que são descritos emValores funcionais do vento. 

Os conceitos a serem explorados são os seguintes:

•When the wind exceeds a certain limit, the wind turbine must disconnect from the grid and position its blades so as to minimize the effect of the wind. This must occur in any situation: that is, if it is in production, it must disconnect; if it is disconnected, it will not attempt to connect. This is the concept of "Max absoluto."
Este valor é controlado neste simulador pelo parâmetro "Controller.WindAbsolutMax," com um valor padrão de30 m/s.

•Quando a turbina eólica é desconectada da grade e o vento excede um determinado valor, entende-se que não vale a pena iniciar uma operação de conexão (cutin) porque estima-se que pode ter que ser parado devido a ventos fortes em breve. Este é o conceito de "Máx. para arranque," que está associado ao parâmetro "ControllerCutin.MaxWindForCutin." O valor padrão é18 m/s.

•Quando a turbina eólica está em produção, há um limite de vento no qual a produção é mantida, mesmo que seja muito superior à velocidade nominal do vento. Este é o conceito de "Max para operação contínua," que está associado ao parâmetro "Controller.WindMaxForOperation," que tem um valor padrão de25 m/s.
Quando o vento excede este valor, a turbina eólica não inicia imediatamente uma operação de desconexão, mas espera por um certo tempo, que depende do comportamento do vento conhecido na localização da turbina eólica.

•Quando a turbina eólica está em produção e o vento ultrapassou "Max para operação contínua"mas não chegou"Máximo absoluto," outro parâmetro é usado, "Controller.WinMaxForTemporalOperation", que tem um tempo de espera mais curto do que no caso de "Max para operação contínua" antes de iniciar a operação de desconexão.
O valor padrão para este parâmetro é28 m/s.

As ideias por trás destes parâmetros referem-se à maximização da produção quando o vento é alto, minimizando os riscos e tensões a que a turbina eólica está sujeita.
