Data recording

This simulator, being an LdP application, keeps in mind the evolution of the different signals that are exchanged between its subsystems.

When you leave it you wonder if you want to save these developments on disk. See figure.

If the answer is "OK," a database file is created in the directory "c:\ WFS _ Datalog\ Eolico Park Simulator\ aa-nn-d-h-mm-ss.sqlite" where "aa-mm-dd-h-mm-ss" corresponds to the date the session began.

"aa" es el año, pe, "16" para "2016"; "nn", es el mes, "dd", es el dia; "hh", es la hora; "mm", es el minuto: y "ss" es el segundo, del comienzo.

This database is exploratory with several tools for free use. The following figure shows the content of the description of an open example with the application "DB Browser for SQLite."

Some of these tools have features to generate graphics. For example, the following figure shows the evolution of power produced by one of the wind turbines in a simulation session.

These data are exportable in several formats (CSV, Excel, etc.) For a full description see the heading "Signal values record (datalogging)"in the tutorial"Introduction to LdP".
