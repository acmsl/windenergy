State management of an aerogenerator

Description of the Eolico Park Simulator ›› Simulator components ›› Main synoptic ››

In a real SCADA there are several procedures to indicate that an aerogenerator "is not available" for production. In this simulator the interface indicated by the figure is available to pass a certain wind turbine to this "Not available" state.

To do this it is necessary to select the wind turbine in the grid (View of the SCADA application).

When an aerogenerator is selected, it appears in the box, as shown in the following figure.

In this situation, if you press the "Put 'Out of Service' button, the application requests confirmation and if it is given, you pass the state of the indicated wind turbine to" Not available. "

If the selected aerogenerator is out of service, the functionality of this button will change, as indicated in the following figure.

At any time it is possible to change the value of the "Efficacy" of the selected aerogenerator by typing a value between 0 and 1 in the corresponding box. This value is used in the calculations of actual production.
