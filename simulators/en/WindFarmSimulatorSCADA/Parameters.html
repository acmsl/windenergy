Parameters

Description of the Eolico Park Simulator ›› Simulator components ›› Control of implementation and access to options ››

This simulator uses the parameters listed in the following figure for internal processes. They can be accessed from the execution control synoptic "Synoptics" -> "Parameters"


The parameter "RandomCoefficient"of the process"Wind"regulates the randomness of wind speed in each aerogenerator.

The parameter "WaitingTimeCancel Proposal"of the process"AutoDispatcher"regulates the maximum time the operator has to cancel the proposal of the start-up or stop algorithm of a set of wind generators in response to a change in wind or demand speed. SeeAutomatic management.

The parameter "SetPointTolerance"of the process"AutoDispatcher"determines which is thepower rangeproduced which is considered acceptable. In% ondemand.

To remove from the screen this form or synoptic must use the "X" icon at the top right.
