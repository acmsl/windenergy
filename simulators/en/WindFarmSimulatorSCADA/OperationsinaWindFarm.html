Operations in a wind farm

In a wind farm production is determined by a set of factors:

•Availability of wind and weather conditions

•Status of each of the aerogenerators.

•Customer's planned demand.

•Maintenance planning.

In this simulator there are user interfaces to be able to change the values corresponding to these concepts.

These factors can be grouped into two large groups:

•Production Control.

•Maintenance Management.
