Control modes

Description of the Simulator ›› Emulated Wind Turbine ›› Controller ››

The Wind Turbine is a machine designed to keep producing energy as much as possible, whenever the conditions for production are met.

So the normal state is "Automatic" or "Wind controlled", meaning that, if it does not receive the STOP command, and there are no pending incidences that must be acknowledge manual,  and the wind is enough, it will try to be  connected to the Grid , to produce energy.


Nevertheless, there are situations where a manual control is required or desired. In the Manual control state, the Operator can issue a number of commands described in the Service Manual.


Those manual commands include "yawing", calibration, etc.

Some commands can be received remotely from, for example, the SCADA system (Supervisory Control And Data Acquisition  system) of the wind farm.
