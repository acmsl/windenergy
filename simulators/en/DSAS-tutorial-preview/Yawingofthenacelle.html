Yawing of the nacelle and the Power Cables

Description of the Simulator ›› Emulated Wind Turbine ›› Controller ›› Algorithms ››

The Yawing system's objective is to keep the Nacelle facing to the wind, so the  Blades' rotate  plane is perpendicular to the direction of the wind. (See Yawing subsystem ).


In the Wind Turbine we are simulating,  this is achieved by means of two independent motors with gears, each one turns  the Nacelle in one direction only. Next figures show details of several implementations of this concept.


As the Nacelle rotates on its vertical axis, so does the power cables of the Generator, that drops from the Nacelle to the base of the Tower, coiling on themselves. Next figures show a schematic view and some examples.



These cables can withstand a maximum number of turns, so the Nacelle rotation also has this limit. There is switch that is activated when the cables torsion is higher that a given limit. When this switch is activated, the Controller removes the power of the yawing motors, starts a shutdown in case the Wind Turbine is in production, and annotates an Incidence that must be acknowledge by the Operator. I.e., this is considered an important issue and the Operator is required to visit the Wind Turbine and investigate what happened. After the Operator acknowledges this type of Incidence then Wind Turbine is ready to start again the cutin process. 

The number of turns of the cables at which this switch becomes activated, in this Simulator, is controlled by the "Parameter.NacelleYawing.MaxCableTwist", that is set to 3.5 turns.

Beside this hardware protection, the Controller includes a Yawing Control Algorithm that tries to keep the number of turns of cables always within reasonable limits. 

The implemented concepts takes into account the fact that to unroll the cables the Wind Turbine must be disconnected from the Grid, as it will cross orientation angle regions in which the wind will hit down side. Therefore untwisting cables is a process in which there is a potential loss of production. The typical approach in many Wind Turbines (and the one used in this Simulator) use two parameters: "Parameter.ControllerYawing.MaxCableTwist" and "Parameter.ControllerYawing.MaxCableTwistBeforeCutin". Their values are 2.5 and 1.5 turns.

•While in production, the Controller monitors if the number of turns of cables is higher than  "Parameter.ControllerYawing.MaxCableTwist": when that happens the Controller shutdown the Wind Turbine and starts rotating the Nacelle so that the number of turns of the cables is reduced to 0. Immediately after finishing this rotation, the Controller starts a new cutin process so the Wind Turbine returns to production, automatically. 

•If the Wind Turbine is stopped and the environmental conditions (wind, temperatures, etc) are ok for going to production (Cutin), and the Controller receives the order for START (either through the Control Terminal by the Operator, or from the SCADA system), then the Controller first checks that the number of turns of the cables is smaller than "Parameter.ControllerYawing.MaxCableTwistBeforeCutin": if it is higher then the Controller first starts the untwisting process before continuing the cutin process.
