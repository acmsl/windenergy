Emulated Wind Turbine

Description of the Simulator ››

As explained in  Basic emulators for a Wind Turbine , each Wind Turbine simulator in LdP is implemented with a number of Synoptics (for the User Interface) and a number of simulators, one for each of the components in the it. These "sub"simulators are implemented with LdP "Processes". Next topics describe them for the Dual Speed Active Stall Wind Turbine.
