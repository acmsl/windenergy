Description of the Simulator

The "Dual Speed Active Stall Wind Turbine simulator" is an LdP application that allows the reproduction of the behavior of a Wind Turbine that has Blade's control by Active Stall method and a Short-Circuited Rotor Induction Generator with two possible connections of its stator (Dual Speed). It consist of a configuration file ("DSASv10.conf") for the LdPv10 framework, and its associated components, together with this tutorial.

As an LdP configuration it consists of "Processes", "Synoptics", "Functions", "Parameters" and "Connections".


A "Process" in LdP is a building block that has no graphical interface. In particular the Dual Speed Active Stall Wind Turbine simulator contains of the following Processes:

A "Synoptic" in LdP is a building block that has a graphical interface through which the User is informed about the values of signals, and can modify some of them. It may contain none, one or more Processes.  In particular the Dual Speed Active Stall Wind Turbine simulator consists of the following Synoptics:

A "Function" is an special type of "Process" that provides a single output signal out of a number of input signals, linked trough a function that is specified explicitly.  There are no Functions used in the Dual Speed Active Stall Wind Turbine simulator.


A "Parameter" is an output signal that can be connected to any input signal of any of the building blocks ("Synoptics" and "Processes"). Their values can be changed in a single Synoptic ("Parameters") that can be access at any moment (see Parameters). The list of parameters in this simulator is the following:
