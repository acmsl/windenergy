StripRecorder synoptic

Description of the Simulator ›› Synoptics ›› Common synoptics of the WorkBench ››

A StripRecorder synoptic helps giving a track record of the evolution of signals, just as a normal paper type strip recorder.

The concepts in this synoptic are:

1.Recorder : Similar to a paper strip-recorder with multiple pens. Past time is progressing to the left, with the current instant always in the right border.

2.Each recorder may present more than one signal.
Each signal has an associated color and have a legend for that association.
Each recorder has its own height but all of them share the same width.
As there is a single scale, all signals presented in a recorder must share maximum and minimum values.
Each recorder can present a single type of signals: analog or digital.
In the digital option, each signal is presented slightly displaced so that if two digital signals have the same value during a portion of time they do not hide each other.

3.A set of Recorders, predefined, is known as "Panel". Panels has an associated name and description.

4.Each pixel in the horizontal direction is associated with a time interval. This interval can be changed with the "Time per pixel" button.

5.It has the capability of making "active" hardcopies.

6.The "Predefined panels" button allows the access to change the panel to visualize in the synoptic.


You can select the timebase for the recorder between 0,2 seconds/tick to 5 seconds/tick.
