Wind limits

What is a Wind Turbine ››



Min for yawing

Wind below which the Wind Turbine will not orient itself to the wind direction automatically

Min for cutin

Wind below which the Wind Turbine will not try to cutin.

Min for Large

If the Wind Turbine is connected in Large mode (4 poles) and the wind descend then it will try to change the mode to Small (6 poles), disconnecting previously from the Grid and reducing the rotor speed so the corresponding generator rpms match the Small mode regime, then reconnecting.

Max for Small

If the Wind Turbine is connected in Small mode (6 poles) and the wind increases then it will try to change to Large mode (4 poles), disconnecting previously from the Grid and reducing the rotor speed so the corresponding generator rpms match the Small mode regime, then reconnecting.

Max to depart

If the Wind Turbine is idle or stopped and the wind speed is higher that this value it will not start any cutin operation. The reason is that if the wind is so high before start most probably will continue in this high value or above, stressing the Wind Turbine. This limit does not apply if the Wind Turbine was connected (made the cutin) with smaller wind and, after that, the wind grew to this limit or even above.

Max for Operation

Wind speed above which the Wind Turbine will disconnect waiting previously a given amount of time, so that if wind speed reduce below this limit in that period it will no disconnect.

Temp max

Similar to "Max for Operation" but waiting a shorter time before deciding to actually cutout.

Abs max

Wind speed reaching which the Wind Turbine will disconnect immediately.
