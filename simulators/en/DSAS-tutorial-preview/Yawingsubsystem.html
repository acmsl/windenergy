Yawing subsystem

Description of the Simulator ›› Emulated Wind Turbine ›› Processes in NacelleEmulator ››

The Nacelle's Yawing mechanism typically includes two set of motors, one for each rotating direction. See Yaw system.

The Yawing process in the NacelleEmulator receives the command signals for the yawing motors (one for each turning direction) from the Controller, and computes the actual Nacelle orientation.

To do that it uses two parameters: "NacelleYawing.CCWYawingSpeed" and "NacelleYawing.CWYawingSpeed" that set the actual speed of change for the Nacelle orientation.

Using these parameters it is possible to simulate problem in the yawing. For example if any of this values is set very small it can mimic the behavior of a motor that has a lot of friction or, by some reason, has lost effective torque.
