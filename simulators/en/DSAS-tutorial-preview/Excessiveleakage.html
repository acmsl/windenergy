Pump malfunctioning

Teaching sessions ›› Monitoring the Brakes hydraulic circuit ››

A typical problem with the pumps in hydraulic circuits is that they may lose pumping capabilities. In this simulator we can simulate that failure changing the value of "Parameter.NacelleBrake.PumpCaudal".

As a previous test, we will observe the evolution of several signals:

•The "Hydraulic pressure" widget you will observe that it descends much faster, and also that the "Pump" is active more often.

•If you select the "Synoptic"->"StripRecorders"->"Hydraylic circuit: Panel to monitor watching operations in the hydraulic circuit of brakes", you will observe a plot as in next figure.

To speed up this session we may increase the leakage, changing  "Parameter.NacelleBrake.LeakageBrakeHydrCircuit" to a value that is still normal but accelerates the cycle. Let's put this value to "0.5". With the default value for "Parameter.NacelleBrake.PumpCaudal" of "5", we should get a plot as next figure, considered "good" working  conditions.

If we change "Parameter.NacelleBrake.PumpCaudal" to "0.5" we will get a plot as next figure

and the "Opened incidences" tab will register message 18 ("Pumping time too long"). If we restore its value to the "normal" one ("5") and acknowledge the incidence the Controller will try to cutin again, automatically.
