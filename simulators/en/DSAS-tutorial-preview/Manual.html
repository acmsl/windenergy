Normally for servicing the Wind Turbine the Operator set the Controller in this mode.


Typically, through a dedicated terminal, the Operator receive information about the status of the Wind Turbine from the Wind Turbines Controller and can exercise a number of functions, ranging from changing parameters for the different algorithms in the Controller, setting On or Off the status of some devices in the Nacelle, reading the some variables (pe, actual orientation of the Nacelle, or the actual pitch in each of the Blades).
