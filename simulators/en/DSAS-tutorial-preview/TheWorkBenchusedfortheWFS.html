The Simulator as a WorkBench

Description of the Simulator ››

This simulator is built on a general purpose simulation  framework (LdP © ACM) and specific configuration files and components.

A basic concept in LdP follows the paradigm of the "wired building blocks", like an electrical panel or enclosure or an electronic system: you have components that implement some functionalities and these components, or building blocks, has input values or signals. These blocks use that input signals to generate other (output) signals. You construct a working system first developing the blocks, then "wiring" input and outputs signals between these building blocks using a "configuration" file.

In the case of this Simulator they have an associated pair of "Nacelle emulator" and "Controller emulator" blocks, each with their independent set of parameters. 

The "Nacelle emulator" encloses all the DriveTrain elements and the braking, together with the computation of production values.

The "Controller emulator" follows the principle of a real Wind Turbine Controller, receiving signals from the Nacelle emulator, the wind data and the Grid variables and elaborating control signals for the elements in the Nacelle, basically the Blades Pitch value and the braking system. It also takes care of the security issues.

Together to these two building blocks, a number of synoptics can be used to present the instantaneous values of the signals connecting these building blocks. For that, the synoptics use several types of "graphical widgets", that are described further down.

Most of these widgets has a dual mode of operation: presentation-only or presentation-and-modification.

The "WorkBench" concept inside the LdP mimics the workbench in a Electronics laboratory. A real workbench has a number of power supplies, signal generators, voltmeters, ammeters, oscilloscopes, etc. Those instruments are wired accordingly to an electronic system, in order to be able to visualize the magnitudes of the signals and, eventually, been able to modify them. That is exactly the spirit of the WorkBench inside the LdP.
