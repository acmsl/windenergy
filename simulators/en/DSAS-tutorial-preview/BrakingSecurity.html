Braking & Security

Description of the Simulator ›› Emulated Wind Turbine ›› Processes in NacelleEmulator ››

The Braking subsystem in the NacelleEmulator uses the following parameters:


Parameter

Use

NacelleBrake.PumpCaudal

Set the pump caudal as a percent respect to the total volume in the circuit

NacelleBrake.LeakageBrakeHydrCircuit

Set the percent of loss of pressure inside the hydraulic circuit due to any reason: valve leakage, connections leakage, pump leakage, etc. In percent.

Nacelle.GeneratorSpeedVCU

VCU limit. If Generator's rpms rises above this limit an specific STOP sequence is started.

Nacelle.RotorSpeedforHCU

HCU limit. If Rotor's rpms rises above this limits an specific STOP sequence is started.
