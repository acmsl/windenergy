Common synoptics of the WorkBench

Description of the Simulator ›› Synoptics ››

The underlying Workbench (LdP) has two type of synoptics named "Signals & Connections" and "Parameters". With  "Signals & Connections"  you can visualize to the defined input and output signals for the building blocks and to visualize and edit the defined connections among them.

There is also a special type of synoptic named "StripRecorder", that contains "Panels definitions" consisting of sets of "Recorders". A recorder in this environment is similar to a paper type recorder you may find in real control systems, where the value of a number of variables (signals) are presentation graphically respect to time. You may launch as many StripRecorders as you like. Once launched you should select among the "Predefined panels". You can change the "panel" to be represented at any moment.

To access any synoptic you have to find the "Control" synoptic (labeled "Executing"). For that you may use standard switching mechanism of Windows (Alt-Tab) or you can go to the Windows status bar and look for the ACM icon. There is one of these icons for every synoptic. Clicking on any one will hide / show the corresponding synoptic.
