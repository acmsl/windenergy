🎯 Monitoring the hydraulic circuit

Objective: To learn how to monitor the hydraulic circuit using pressure and status variables to detect deviations.

What to observe: System pressures, pump and valve status, and possible alarms.

What to note: Normal operating values and which variable changes first when an anomaly occurs.

💡 Identify the element that deviates first when an alarm occurs.

  1. When a shutdown process is initiated during production, is the hydraulic brake used?
  2. What criteria does the controller use to detect a problem in the hydraulic system and what variables does it monitor?

Observation of temperature detectors

Practical classes ››

This practical exercise involves observing the controller's reaction when the temperature sensors of several key components exceed the limits for normal operation.

Make sure that the wind turbine is in production (see Setting the conditions for entry into production with low wind).

Display the "SynopticDriveTrain" synoptic (see How to bring a specific synoptic to the foreground).

Change the View (first option in the menu) to "Inside the Nacelle." Set the "Instrumentation View" to "Hidden" (second option in the menu), and click on the third option, "Temperatures," to display the temperature indicators. See the following figure.

The "Ambient Temp," "Rotor Temp," "Multiplier Temp," and "Generator Temp" indicators have a red border, which means they are in 'command' mode. You can modify their values in several ways:

•By moving the bar with the mouse.

•Using the "Page Up," "Page Down," "Up Arrow," and "Down Arrow" keys.

•By typing the desired value directly. If you change the value and the display does not match the previous one, the background turns yellow: you must press "Enter."

The Controller continuously monitors the values in these indicators, comparing them with the values of the parameters "Controller.TempMaxGenerator," "Controller.TempMaxGearBox," "Controller.TempMaxAmbient," and "Controller.TempMaxRotorBearing."

In this exercise, you must increase the value in each of these indicators and observe that, when the temperature exceeds the value of the corresponding parameter for a certain period of time, the Controller initiates a process to disconnect from the grid and stop the wind turbine, generating a specific incident.

If the temperature drops below the limit once the incident has occurred, you will see that the "Recovered" column in the "Open Incidents" table records the moment when this happens.

Note that the treatment of "Ambient Temp" is different from the others: when the maximum allowable ambient temperature is exceeded, the corresponding incident is generated, with the wind turbine stopping; however, as soon as this temperature drops below its maximum limit, the incident automatically moves to the "Incident History." In other cases, the operator must "acknowledge" the incident (checkbox "Ok") before it is moved to the "Incident history."
