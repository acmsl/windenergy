Observation of excessive pressure loss failure in the circuit

Practical classes ›› Monitoring the hydraulic brake circuit ››

In this practical session, we will observe the protocol implemented by the controller to deal with a common problem of excessive pressure loss in the hydraulic circuit.

These leaks can come from any of the elements: hoses, pipes, the valves themselves, or the pump.

This problem is simulated in this simulator by modifying the "NacelleBrake.LeakageBrakeHydrCircuit" parameter.

To create the fault situation, we can increase the default value (0.01 out of a maximum of 10) to a value 100 times higher (1). To change the value, follow the instructions described in Changing a parameter value.

You will see that after a short time the Controller issues an incident with the description "Pump starts too often" and disconnects the generator from the grid. In the logger you will see a signal evolution similar to that shown in the following figure.

If you now restore the default value for losses, which is equivalent to having repaired the fault, you will see that the Controller does not immediately start the process of connecting to the grid: this is because the mechanism for checking that 'everything is OK' requires that: a) the pressure in the circuit is restored, and b) the time between two pump starts is 'sufficiently long'.
