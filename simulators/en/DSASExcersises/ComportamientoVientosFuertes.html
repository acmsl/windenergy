🎯 Behavior in strong winds

Objective: Relate gusts/high winds to protection and control strategies.

What to observe: Wind speed, alarms/protections, and status changes.

What to note: Gust events, action taken, approximate thresholds, and final status.

💡 Distinguish between limitation (reduction) and shutdown (cut-out).

Behavior in very strong winds

Practical classes ››

This practical exercise involves experimenting with behavior in response to wind values, in accordance with the description of winds in Functional wind values. 

In the practice Power cable unwinding, the influence of the wind values "Min for orientation" and "Min for start-up" is observed. In this practice, we propose observing the influence of the wind values "Max for start-up," "Max for continuous operation," "Max for temporary operation," and "Absolute max," which are described in Functional wind values. 

The concepts to be explored are as follows:

•When the wind exceeds a certain limit, the wind turbine must disconnect from the grid and position its blades so as to minimize the effect of the wind. This must occur in any situation: that is, if it is in production, it must disconnect; if it is disconnected, it will not attempt to connect. This is the concept of "Absolute Max."
This value is controlled in this simulator by the parameter "Controller.WindAbsolutMax," with a default value of 30 m/s.

•When the wind turbine is disconnected from the grid and the wind exceeds a certain value, it is understood that it is not worth starting a connection operation (cutin) because it is estimated that it may have to be stopped due to high winds shortly. This is the concept of "Max for start-up," which is associated with the parameter "ControllerCutin.MaxWindForCutin." The default value is 18 m/s.

•When the wind turbine is in production, there is a wind limit at which production is maintained, even if it is much higher than the nominal wind speed. This is the concept of "Max for continuous operation," which is associated with the parameter "Controller.WindMaxForOperation," which has a default value of 25 m/s.
When the wind exceeds this value, the wind turbine does not immediately initiate a disconnection operation but waits for a certain time, which depends on the known wind behavior at the location of the wind turbine.

•When the wind turbine is in production and the wind has exceeded "Max for continuous operation" but has not reached "Absolute max," another parameter is used, "Controller.WinMaxForTemporalOperation," which has a shorter waiting time than in the case of "Max for continuous operation" before starting the disconnection operation.
The default value for this parameter is 28 m/s.

The ideas behind these parameters refer to maximizing production when the wind is high, minimizing the risks and stresses to which the wind turbine is subjected.
