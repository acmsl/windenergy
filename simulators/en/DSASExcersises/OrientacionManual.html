🎯 Manual Guidance (Yaw)

Objective: To understand manual orientation control and its operational limits.

What to observe: System response to manual commands and permission statuses.

What to note: Under what conditions the system allows or blocks manual action.

💡 Compare behavior in automatic and manual modes.

Manual orientation

Practical classes ›› Effects of changes in wind direction ››

In this practical exercise, you will use the "Manual Yaw" buttons on the "Control Terminal" to manually command the nacelle to turn. The arrows on each button indicate the direction of rotation.

Be sure to view both the "SynopticWindNacelle" synoptic and a recorder with the "Yawing" panel.

Note that the nacelle rotates when you use the "Manual Yaw" buttons. When one of these buttons is pressed, the corresponding indicator in "SynopticWindNacelle" and in the recorder is shown as active.

As an exercise, hold down one of the "Manual Yaw" buttons. Check that the nacelle stops turning when the number of turns of the power cables reaches the physical limit (3.5 turns). If this happens, you will see an "Open Incident" appear with the description "Cables max twisting." If you press the other "Manual rotation" button, you will see that this incident changes to "Recovered," and that you must fill in the "Ok" box for it to move to "Incident history."

The rotation speed (in degrees per second) is determined by the parameters "NacelleYawing.CWYawingSpeed" and "NacelleYawing.CCWYawingSpeed." The default values, which are identical in both directions, are 10 degrees/second. In a real wind turbine, this speed is around 0.5 degrees/second.
