🎯 Observation of the hydraulic circuit

Objective: To identify the function of the hydraulic circuit and recognize symptoms of abnormal operation.

What to observe: Pressure, pumps/valves, actuator status, and related alarms.

What to note: Normal vs. abnormal values and what evidence supports your diagnosis.

💡 If there are alarms, note the first one that appears and what variable changes just before it.

Monitoring the hydraulic brake circuit

Practical classes ››

The following practical sessions aim to familiarize you with the hydraulic brake circuit and explore various problems that may occur in its operation, as well as the procedures implemented by the controller to detect them and generate incidents.

You must first familiarize yourself with the behavior of this system, which is essential for the safety of the wind turbine. The Brake System section provides a general description and some industrial examples. The Brake System section provides a description of the graphic elements presented in the "SynopticDriveTrain" synoptic that present and/or control the variables associated with this system. The signals involved are as follows

Output signals

Nacelle.Braking.BrakeReleasedOut

Comes from the physical brake simulator in the nacelle.

If it is 'On', it indicates that the brake shoe is not touching the disc, i.e. the power train is released. This occurs when the pressure in the hydraulic circuit is higher than the value indicated by the yellow line on the circular "Brake circuit pressure" indicator.

Nacelle.Braking.PressureSwitchOut

Corresponds to the pressure switch output: if it is 'On', the pressure in the hydraulic circuit is higher than the upper value of the green zone.

If it is 'Off', it is below the lower value of the green zone.

Controller.Control.HardBrakeOut

Brake valve control signal.

Controller.Control.PumpOut

Pump control signal.

Input signals

Nacelle.Braking.PumpIn

Control input to the pump.

Nacelle.Braking.ValveHardBrake

Control input to the quick discharge valve.

Nacelle.Braking.ValveSoftBrake

Control input to the normal discharge valve.

Nacelle.Braking.PumpFlowIn

Descriptive value of the pump flow rate. Connected to "Parameter.NacelleBrake.PumpFlow".

Nacelle.Braking.LeakageBrakeHudrCircuit

Descriptive value of the 'pressure loss status' in the circuit. 

Corresponds to the aggregate value of pressure losses in hoses, pipes, valves, and pump.

Connected to "Parameter.NacelleBrake.LeakageBrakeHudrCircuit".

Controller.Control.PressureSwitchIn

Pressure sensor input in the circuit. This is a digital signal, so it does not correspond to a meter per se.

Controller.Control.BrakeReleaseIn

Input from the sensor measuring the separation between the disc and the brake pad.
