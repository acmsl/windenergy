Changing configuration connections

Wind Turbine Simulator with Active Stall and Two Speeds ›› The Simulator as a Laboratory Workbench ››

It is possible to change the existing connections in the simulator configuration without having to stop the simulation: this feature opens up many possibilities for its use as a test bench.

To do this, you need to access the "Running Two-Speed Wind Turbine Simulator" synoptic, "Synoptics" menu, "Signals and Connections" option. A form like the one in the following figure will appear.

Each row corresponds to a connection between an "Output" signal and an "Input" signal. If you select a row, you can use the "Sup" key to delete that connection.

For a complete description of this functionality, see the "Introduction to LdP" tutorial.
