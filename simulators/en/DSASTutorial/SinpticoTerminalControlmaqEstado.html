Controller state machine indications

Wind Turbine Simulator with Active Stall and Two Speeds ›› Synoptics used in this simulator ›› Control Terminal Synoptic ››

This synoptic displays the current data from the controller's state machines.

State machines are a paradigm for describing the part of the Controller that coordinates the different control algorithms of each of the subsystems (Operations) and is also responsible for monitoring machine security (Security). 

State machines receive specific "events" that can potentially change their "state." The central part of this synoptic shows the last event received and the current state of each of the two state machines.

The "Messages" tab shows the sequence of events that are generated, with their date.
