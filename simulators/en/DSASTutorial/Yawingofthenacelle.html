Algorithms for controlling the orientation and unwinding of power cables

Wind Turbine Simulator with Active Stall and Two Speeds ›› Scope of the Simulation ›› Controller ›› Algorithms used ››

The Controller contains an independent process specific to the following functions:

•Orientation of the nacelle to the wind direction.

•Unwinding of power cables

The implemented algorithm takes into account the concepts of:

•'maximum number of turns of the power cables before starting the connection (cutin)'.

•'maximum number of turns of the power cables'. This value is not the same as the maximum limit set by the limit switch associated with these cables, which is controlled by the parameter "Parameter.NacelleYawing.MaxCableTwist", with an initial value of 3.5 turns.

•'minimum wind speed for unwinding the cables'.

In addition, this process takes into account the current operating mode: "Manual" and "Automatic." See Modes.

For the power cable unwinding process, it is first necessary to disconnect the wind turbine from the grid (cutout), using the normal protocol (without imposing short response times).

When the number of cable turns is within the first turn, the Controller initiates the process of connecting to the grid (cutin) without any intervention by the operator.

The following graph shows the relationship between the parameters mentioned and the states.

•If the wind turbine is in the process of connecting to the grid (cutin) and the number of turns is greater than 1.5, then the unwinding process is started before continuing.

•If the wind turbine is in production and the number of turns exceeds 2.5, the controller initiates a process of disconnection from the grid, followed by unwinding and connection to the grid.

•In any case, for example, when using manual control for nacelle orientation, if the number of turns reaches 3.5, the controller stops the nacelle from turning.
