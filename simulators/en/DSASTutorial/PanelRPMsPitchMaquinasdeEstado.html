'Controller State Machines' Panel

The following figure shows the panel called 'State Machines', which contains 4 channels.

1.The first 'channel' displays a signal corresponding to the last event received by the Safety state machine implemented in the Controller. See Safety State Machine.

2. The second 'channel' displays a signal corresponding to the current value of the Security state machine status.

3. The third 'channel' displays a signal corresponding to the last event received by the Operation state machine implemented in the Controller. See Operation State Machine.

4. The fourth 'channel' displays a signal corresponding to the current value of the Operation state machine.

This panel is very useful for following the action protocols implemented in the Controller to respond to different circumstances and operations.
