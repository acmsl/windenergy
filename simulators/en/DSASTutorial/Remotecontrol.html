Remote control from SCADA

In Automatic mode, the Controller waits for commands sent to it via the data line, which is normally connected to the Wind Farm Control Center where the wind turbine is located.

The commands are generally:

•Data request: the Controller responds with a message that includes various operational data from the wind turbine: Status (in Production/Stopped/Faulty), measured wind speed, wind direction, instantaneous power (Active and Reactive), accumulated energy produced, temperatures in various elements, etc.

•STOP: start the operation to disconnect from the grid (cutout)

•START: start the grid connection operation (cutin)

•Active power setpoint change: this functionality is not implemented in the wind turbine that simulates this configuration.

•Change in reactive power setpoint: this functionality is not implemented in the wind turbine that simulates this configuration.
