Panel 'RPMs + Pitch + Status Machines'

The following figure shows the panel called 'RPMs + Pitch + State Machines', which contains 6 channels.

1.The first 'channel' shows a single signal with the rotational speed of the electric generator shaft (in RPMs).

2. The second 'channel' presents two signals:

1.Signal generated in the Controller and used as the setpoint value for the blade pitch.

2. Signal from the hub simulator, with the actual pitch value of the blades.

3. The third 'channel' presents a signal that corresponds to the last event received by the safety state machine implemented in the Controller. See Safety State Machine.

4. The fourth 'channel' presents a signal that corresponds to the current value of the Security state machine.

5. The fifth 'channel' displays a signal corresponding to the last event received by the Operation state machine implemented in the Controller. See Operation State Machine.

6. The sixth 'channel' displays a signal corresponding to the current value of the Operation state machine.

This panel is very useful for following the action protocols implemented in the Controller to respond to different circumstances and operations, in relation to key mechanical variables.
