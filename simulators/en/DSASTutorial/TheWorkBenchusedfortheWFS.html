The Simulator as a Laboratory Workbench

Wind Turbine Simulator with Active Stall and Two Speeds ››

A simulator corresponds to the execution of a specific configuration on the LdP platform (©ACM).

Each configuration can specify a number of:

•Processes:
For example, in this simulator, one process is the monitoring and control of the nacelle's orientation with respect to the wind direction. Another is the control of the number of turns of the power cables. Another is the control of the pitch, etc.

•Synoptics:
These constitute the graphical interface of the simulator. They may contain processes. They feature graphical indicators, which may also be control indicators, to display the values of certain variables or change their values.

•Parameters:
Each of the defined processes can have a certain number of parameters. The parameters in LdP allow the user to access their display and modification, as well as their registration. (See the tutorial "Introduction to LdP".)

•Connections between the above elements.

•Striprecorders:
These are sets of graphical recorders of the evolution of a selected set of variables, designed specifically for a simulator.

(See a detailed description in the tutorial "Introduction to LdP").

These processes behave like virtual replicas of real physical elements in electrical cabinets, so that they can be interconnected with each other: with output terminals connected to input terminals.

These connections, as well as the value of the parameters, can be modified in real time; that is, they can be deleted or created even while the simulation is "running." These concepts correspond to changing the connections in an electrical cabinet or certain parameters of elements in such cabinets while the simulation is running. In this way, LdP simulators behave like highly flexible "laboratory workbenches."

The following figure shows an example of these possible connections in this simulator.

This figure shows two blocks that group the processes described. Both sets of processes must be properly connected to each other. One of the signals, in this case the revolutions of the electric generator, comes from one of the processes in the nacelle group and must be connected to one or more processes in the controller. In the case of the figure, this signal "passes through" the set of indicators: text, slider, and clock, where the current value is displayed, before connecting to the Controller.

As some of these graphic indicators, for example, the text box or the slider, can be "set" to command mode (by pressing the "F6" key), this arrangement allows you to simulate (without making any changes to the simulator configuration) a fault that could be equivalent to a break in the generator shaft speed sensor. For a complete description of the functionalities of the graphic indicators in the LdP Synoptics, see the topic "The LdP as a workbench" in the "Introduction to LdP" Tutorial.
