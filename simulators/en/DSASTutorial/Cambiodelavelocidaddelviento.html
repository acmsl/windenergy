Change in wind direction

Wind Turbine Simulator with Active Stall and Two Speeds ›› Synoptics used in this simulator ›› Nacelle and Wind Orientation Synoptic (SynopticWindNacelle) ››

To change the wind direction, use the text box labeled "Wind Direction."

The change can be made by entering this text box (left-click with the mouse) and typing in the desired value. You will see that when the value is changed, the background turns "yellow": this indicates that the value currently being read and the actual value being used are not the same. When you press "return" on the keyboard, the value entered will become the current value, and the background of this text box will return to white.

If you change your mind about changing the value once you have started this operation, simply press the "Esc" key on the keyboard (top left).
