Problem detection logic in contactors

The logic for detecting the position of a contactor using two wires is to use an XOR function.

Fig. 1

It starts with two contacts that are mechanically connected to the main contactors, which are represented in Fig. 1 by the two contacts connected to the "NC" (Normally Closed) and "NO" (Normally Open) inputs, respectively.

The "Status" signal that reaches the Controller corresponding to the status of the contactor is associated, in the diagram in Fig. 1, with the "NC" input. There is another signal that also reaches the Controller (OK/Fault) that "validates" the "Status" signal. This signal corresponds to the XOR logic function, applied to both signals coming from the Contactor.

The mechanical and electrical design of the NC and NO contacts is such that both signals must have opposite values during normal operation. The logic table for the XOR function is as follows:

The value of the OK/Failure signal, taking into account failure situations, is as follows: 

1. If +Vcc has no voltage, both NC and NO will have 0 volts → Status = False and OK/Fail = False

2. If the wires connecting the contacts in the Contactor and the Controller are both broken, both NC and NO will have 0 volts → Status = False and OK/Failure = False

3. If only one of the two wires connecting the contacts in the Contactor and the Controller is broken, then when there is a change in the value of the one that is not broken, both NC and NO will have the same value and therefore → OK/Failure = False
