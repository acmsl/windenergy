Functional wind values

Technical data of the emulated subsystems ››



Min for orientation

Wind below which the Controller will not start the protocol to track wind direction.

Min for start-up

Wind speed below which the Controller will not initiate the connection operation with the Grid (cutin).

Min for Large Gen

If the wind turbine is in production, with the large generator connected, and the wind falls below this level, it will initiate the operation to switch from the large generator to the small generator.

Max for Small Gen

If the wind turbine is in production, with the small generator connected, and the wind exceeds this level, the controller will initiate the operation to switch from the small generator to the large generator.

Max for start-up

If the wind turbine is disconnected from the grid and the wind is above this limit (normally well above the nominal wind speed: for example, 18 m/s) and the controller receives the command to initiate connection (cutin), it will not do so unless the wind drops below this level.

This limit has no influence if the wind turbine is in production and the wind exceeds this limit.

The reason for this limit is statistical, so it must be adjusted for each wind farm. The aim is to avoid starting up the wind turbine if it is suspected that the wind is so strong that it will soon exceed the maximum continuous operating wind speed and therefore have to be disconnected.

Max for continuous operation

Upper limit at which the wind turbine can remain in production. If the wind remains at this level or slightly above it for a certain period of time, the controller proceeds to disconnect.

Max for temporary operation

Similar to "Max for continuous operation," this is a higher value, but the controller waits less time to proceed with disconnection if the wind remains at or above this level.

Absolute max

If the wind reaches this value, the controller immediately proceeds to disconnect.
