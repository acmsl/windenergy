How to present a Logger and choose a predefined Panel in it.

Wind Turbine Simulator with Active Stall and Two Speeds ›› Synoptics used in this simulator ››

"Recorders" are synoptics that display the evolution of signals over time.

A "Recorder" can display several predefined groups of signals, but only one at a time. These groups of signals are called "Predefined Panels," and have been defined with the visualization of specific signals for certain observations in mind.

Each Panel contains a number of "channels," which display one or more signals that are "congruent in terms of values." Each signal is assigned a color for identification purposes.

You can create as many Recorders as you want. To do this, go to the "Running Simulator..." synoptic and click on the "Synoptics" --> "Recorders" button.

Any Recorder can be closed using the "X" button in its upper right corner.

In any Recorder, you can change the "Predefined Panel" that is displayed in it: however, this will cause the current content of the Panel being used to be lost. You can make a "Copy" beforehand using the corresponding button in its menu.

You can also change the "sampling period" of the signals displayed using the first button on the right-hand menu "Seconds per pixel xx": the possible values are 200 ms, 500 ms, 1 second, 2 seconds, 5 seconds. Changing the value of this period will delete the current content of the Panel.
