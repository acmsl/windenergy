Basic structure of the emulation used in this simulator

Wind Turbine Simulator with Active Stall and Two Speeds ››

How 

This simulator consists of two sets of simulation subsystems: one for each of the physical elements residing in the nacelle, and another that simulates the controllers for each of those subsystems. These controllers are usually implemented using appropriately programmed industrial computers (which is the case with this simulator), or using PLCs (Programmable Logic Controllers). 

The resulting structure is illustrated in the following figure.



The lines with arrows indicate the flow of data: 

•The emulation of the real sensors (left side) supplies data to the corresponding controllers (right side).

•The control algorithms, which are executed on the right side, supply commands and setpoint values to the simulators of the physical elements, which are located on the left side.

The arrows indicate interconnections between these elements, which are made using output and input signals. These connections correspond to physical connection cables or elements connected to a bus system (e.g., CANBus, FieldBus, etc.) existing in real wind turbines, and are 'editable'. In other words, they can be created or deleted at will by the simulator operator. This is one of the basic features of the framework on which this simulator (LdP) is developed. See a detailed description of these concepts in the tutorial "Introduction to LdP."
