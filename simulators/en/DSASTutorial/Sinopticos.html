Synoptics used in this simulator

Wind Turbine Simulator with Active Stall and Two Speeds ››

Synoptics with the simulator user interface. They contain a set of graphic elements (widgets) that display the values of certain simulator variables, and have the most appropriate form (linear, circular, etc.) for the type of variable and its range of values.
Some of these graphic elements also allow you to control the value associated with the variable.

A general description of the functionality of these graphic elements can be found in the LdP platform help file (../LdP_Help/LdP_Help.html?Introduccion.html).

There are two types of synoptics used in LdP:

1. Those that allow the simulation of a configuration to be run, the parameters of the subprocesses defined in that configuration to be displayed, the connectivity between subprocesses to be edited at runtime, and graphical recorders to be presented: these are known in LdP as "Common Synoptics."

2. Synoptics that are defined in the configuration being executed.
