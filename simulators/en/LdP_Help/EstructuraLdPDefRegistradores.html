Each Tutorial includes a series of Panels consisting of Recorders that the author considers appropriate for the configuration. This series is grouped under the (single) element "StripRecorders."

Example:

<StripRecorderPanels backColor="1" borderColor="0">

<Panel name="Pitch, Power, Brake, RPMs, Wind" description="General Panel">

        <MarkLine value="90.0" label="90" alphaValue="130" color="0,0,0"/>

        <MarkLine value="45.0" label=" 45" alphaValue="130"/>

        <MarkLine value="-5.0" label="-5" alphaValue="130"/>

      </Recorder>

Description of Elements Associated with StripRecorders

StripRecorders

 This element has two "properties" or "attributes"

Property

Description

backColor

This property determines the background color of the Panels. The possible ways to specify this color are as follows:

="0" : black background color.

="1" : white background color.

="R,G,B" , where R, G, and B are integer values between 0 and 255.

Example: "200,200,200" produces the following background color.

borderColor

="0" (Future use).

Panel

This element has two properties, "name" and "description," both of which are text. Each panel corresponds to a synoptic. It can contain one or more "Recorder" elements.

Recorder

This element can contain one or more "Signal" elements and zero, one, or more "MarkLine" elements. It has the following properties:

Property

Description

type

Required. Can be "A" if you want to represent analog signals, or "D" if they are digital.

name

Required. Used for identification.

maxValue

Required. Upper value of the vertical axis of values.

minValue

Required. Lower value of the vertical axis.

height

Required. Height of the Recorder in pixels.

scaleMode

Optional. Values can be "lin" or "log". The default value is "lin".

If "lin", the signal value scale is linear.

If "log", the signal value scale is logarithmic.

Signal

This element specifies one of the signals to be represented in the "Recorder" element within which it is defined. The color can be chosen.

Property

Description

type

Required. Can be "A" if you want to represent analog signals, or "D" if they are digital.

name

Required. Must correspond to the name of a valid "signal." See Synoptic for editing Signals and Connections.

color

Required. ="R,G,B", where R, G, and B are integer values between 0 and 255.

MarkLine

This element displays a horizontal line corresponding to a possible value of the signals represented in the "Recorder" element where it is defined. The color and transparency can be changed. The associated text is displayed to the right of the ordinate axis.

Property

Description

value

Required. Associated value. Examples: "10.0", "-15.0", "1e-4", "-2e+8".

label

Required. Text displayed to the right of the y-axis.

color

Required. ="R,G,B", where R, G, and B are integer values between 0 and 255.

alphaValue

Required. Value between 0 and 255 corresponding to the degree of transparency of the horizontal line drawn. 0 is completely transparent. 255 is not transparent.
