Exporting data to Excel

Structure of LdP applications ›› Signal value logging (datalogging) ››

The SQLiteAdministrator desktop application (http://sqliteadmin.orbmu2k.de/) has an option to export SQlite file data to Excel.


The Firefox "SQLite Manager" plugin also allows you to export the results of a query to a CSV (Comma Separated Values) file.

These files can be imported into Excel workbooks. The latest versions of Excel include a format that correctly displays the date format with millisecond resolution. See the following figure to observe the translation of the "Date" column (column "A") to the translated form (column "B"), which is represented with the cell format "dd/mm/yyyy h:mm:ss,000".
