The LdP as a workbench

Structure of LdP applications ›› Basic concepts ››

As indicated in Basic Concepts, a simulator developed in LdP can be represented as an electrical diagram in which there are different blocks that are assumed to perform certain operations (parts of the simulator) that receive a set of signals and generate other signals that are assumed to be used by other blocks.

These blocks are interconnected by "connections," equivalent to physical cables in an electrical panel. The following figure illustrates this concept.


Additionally, LdP has mechanisms that allow it to function as a "test bench" or "workbench." The idea is to facilitate changing the conditions under which the simulator runs and observe its responses to those changes. To this end, it is assumed that each simulator has the appropriate synoptics, adapted to the simulation needs of the equipment or system to be simulated. Here are some examples:

In addition, LdP has indicators/controls that are graphical elements used to display signal values and also to force the values of other signals. These indicators, available to developers of LdP-compatible synoptics, have been designed to minimize the screen space required to design a user interface that is both comprehensive and not overwhelming.

These LdP components are described in the following section and their main feature is that they can be used both to indicate the value of a signal and to force that value manually.

Additionally, LdP has "Recorders" to visualize the evolution of changes in certain signals chosen as significant, as well as a connection editor (which allows the concept of a broken cable to be simulated) and another parameter editor, characteristic values of simulation units within the general simulator.
