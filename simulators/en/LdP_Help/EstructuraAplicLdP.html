Structure of LdP applications


LdP (acronym for "Process Language") is a platform for the execution and development of Real-Time Simulators, which implements the concept of a "workbench" in which it is possible to interact with these simulators.

The user interface is implemented through Synoptics, both general LdP Synoptics and specific Synoptics for each Simulator. These Synoptics contain indicators and/or buttons associated with different internal signals of the Simulator.

LdP handles the concept of "Process" as an element where the behavior of one of the Simulator components is implemented.

The Synoptics and Processes of a Simulator are components that connect with the paradigm of electrical components in an electrical circuit: the output signals of any of them can be connected to one or more input signals of any of them.

Synoptics can contain none, one, or several Processes. Processes can be components in themselves, independent of Synoptics.

•Each Process simulates a subsystem in the equipment to be simulated.

•The human-machine interface is specified in the design of the Synoptics, which must have the appropriate indicators so that the user can know the values of the internal signals at all times and in the best possible way. The value of a signal can be displayed and/or used in more than one Synoptic.
