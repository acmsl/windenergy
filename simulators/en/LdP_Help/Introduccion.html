Introduction


LdP is a real-time simulator development and execution environment developed by Automated Computing Machinery S.L. (www.acm-sl.com) (hereinafter referred to as ACM SL).


Its main features are:

•It is a Windows desktop application.

•It is based on the extensive use of Windows ActiveX components and DLLs. These components can be developed in various programming environments (MS Visual Studio VC++, Visual Basic, Delphi, etc.).

•Each Simulator is described in a configuration file.

•The connections of the components in the configuration file can be edited at any time, even while the simulation is running. The connections mimic the concept of connection between electrical or electronic components: the outputs of some can be connected to the inputs of others. Both output and input connections are called "signals" in LdP. Signal names have a three-field nomenclature: "ComponentName"."ProcessWithinComponent"."ProperName." For example: "Controller.Control.PitchOut" refers to an output named "PitchOut" from the "Control" process of the "Controller" component, as declared in the configuration file.

•The basic functionalities available for each Simulator without additional programming are:

oReal-time recording of changes in each of the signals (datalogging) in standardized database files.

oAvailability of recording forms (Recorders or StripRecorders) through which signal evolutions are displayed in real time.

oConnections and parameters can be changed during the execution of the simulation, without the need to restart it.
