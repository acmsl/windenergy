Editing Connections

LdP Application Structure ›› Basic Concepts ›› Simulation Control ›› Execution Control Synoptic ›› Synoptic for Editing Signals and Connections ››

LdP allows you to add and remove connections, even during simulation execution. To do this, the "Internal Connections" tab in the "Signals and Connections" synoptic has two functions:

To add a connection

•First select the "input signal" you want to connect: to do this, use the combo box associated with "Input Signals" in the "Internal Connections" tab. See the following figure.

This action displays the set of "Input Signals" that are not connected.

•In the combo box associated with "Output Signals," select the "output signal" to which you want to connect the "input signal" selected in the previous step.



NOTE: Since an "output signal" can be connected to more than one "input signal," the list that appears corresponds to all "output signals" of the type compatible with the "input signal" previously selected.

• Press the "Add connection" button


Remove a connection

To remove a connection, simply select it from the list of connections (by clicking with the left mouse button) and press "Delete" on the keyboard. The following message will appear:

where you must confirm or cancel the operation.
