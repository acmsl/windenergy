Simulation Control

LdP Application Structure ›› Basic Concepts ››

LdP has a Control synoptic that allows the following functionalities:

•Execution of a configuration file (Run, Stop, Continue).

•Control of the graphical display of configuration synoptics on screen.

•Editing the values associated with Parameters.

•Editing connections.

•Access to the set of tutorials associated with the configuration being executed.
