Signal value recording (data logging)

Structure of LdP applications ››

LdP records changes occurring in each of the Simulator signals in a database in a completely transparent manner. The temporal resolution of these records is 1 millisecond.

This recording is independent of any visible synoptic recorders.

Each "session" of each configuration (simulator) creates a database file. The name of this file corresponds to the start date of the session and is located in a subdirectory named after the configuration. For example, the file "C:\WFS_Datalog\WFS_SCADA\10-10-04-15-20-35.sqlite" corresponds to a session of the "WFS_SCADA" simulator that began on October 4, 2010, at 3:20:35 p.m.

The files are of the "SQlite" type (see SQLite org) and their structure is described in Structure of the log databases.

These files are written at the end of the session, provided that the user responds affirmatively to the message that appears after clicking "Exit" and confirming the exit.
