Basic components

Structure of LdP applications ›› Basic concepts ››

An LdP application (Simulator) is defined by a description in a configuration file, in which:

•Each of the components used in the Simulator is declared.

•The connections between the output and input signals of each of the components are declared.

•Auxiliary elements are defined: parameter values, help, definition of graphic recorder configurations, etc.

The "components" of an LdP configuration can be of the following types:

Processes

This element can contain none, one, or more "Process" type elements. Each of these refers to a DLL developed specifically to simulate a particular aspect or subsystem.

Synoptics

This element can contain one or more "Synoptic" type elements. These elements refer to DLLs developed specifically using graphic indicators. They constitute the user interface.

Connections

This element contains "InternalConnection" type elements. These elements contain one "output signal" and one or more "input signals."

Parameters

This element contains none, one, or more "Parameter" type elements. Each of them has an associated "output signal" with a name associated with a Process or Synoptic. There is a base Synoptic ("Parameters") that allows you to access these "Parameters" and change the associated value. It is usually used to define parameters of algorithms implemented in the different "Process" and "Synoptic" elements.

StripRecorders

(Recorders) This element contains a set of "Panel" type elements, each of which defines the content and format of "Recorders," through which the set of signals presented and the form of representation are defined.

Functions

Element containing none, one, or more "Function" type elements. Each of these elements implements a "formula": each formula has an associated output signal and a set of input signals corresponding to the variables it uses.
