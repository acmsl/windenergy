The following table shows a description of the functions associated with each of these buttons.

Allows you to exit the program.

These buttons allow the simulation to be run. When you press the "Stop" button, the Simulator signals are suspended.

You can resume execution by pressing the "Continue" button.

This button controls the visibility of all synoptics, both those common to LdP ("Signals and Connections," "Parameters," and "Recorders") and those specific to the Simulator being executed.



The visibility of the synoptics can also be controlled using the icons installed in the Windows toolbar.

This button allows you to access the tutorials associated with the Simulator that is running.

This button expands the synoptic to include a message area that the application can send to the user. It is mainly used for debugging configuration files.

This button allows access to information about the version of LdP and the Simulator that is running.

It also allows access to information about the product's user license. See Version and License Information.
