Practical Lab 4: Cable Untwisting Procedure

Objective:

Understand how the turbine manages power cable twist to prevent damage. You'll learn:

  • How cable twist accumulates during normal operation
  • When and why the Controller initiates cable untwisting
  • The complete untwisting sequence step-by-step
  • How the Controller tracks cable twist count
  • The relationship between nacelle rotation and cable twist
  • Production loss during untwisting and optimization strategies

Background - The Cable Twist Problem

Before we begin, let's understand why this is necessary:

The Setup:

Power cables run from the generator (in the nacelle) down to the tower base:

  • Generator is in the nacelle (rotates to follow wind)
  • Grid connection is at tower base (doesn't rotate)
  • Cables must bridge this rotating-to-stationary transition

The Solution:

For the first 5-10 meters, cables hang freely:

  • Forms a "twist zone"
  • Allows nacelle to rotate
  • Cables twist as nacelle turns

The Problem:

Cables have limited twist capacity:

  • Too much twist → insulation damage
  • Cable strands can break
  • Eventually: cable failure → very expensive!

The Limit:

Typical maximum: ±2.5 turns (rotations) in either direction

  • Total range: 5 complete rotations
  • Beyond this → damage risk increases rapidly

Why Not More?

Could use slip rings (rotating electrical contacts):

  • ✗ High electrical losses
  • ✗ Maintenance intensive (brush wear)
  • ✗ Expensive
  • ✗ Less reliable over 20-year turbine life

So the cable twist method is actually better, despite requiring periodic untwisting!

How Twist is Tracked

No Direct Sensor!

Surprisingly, there's usually no sensor directly counting cable rotations. Instead:

Method: Position Tracking

The Controller:

  1. Knows the nacelle's starting position (reference point set during installation)
  2. Tracks every yaw movement
  3. Calculates cumulative rotation from start

Example:

  • Starting position: 0° (facing North)
  • Wind from East → nacelle yaws to 90°
  • Twist count: +0.25 turns (90°/360° = 0.25)
  • Wind shifts to South → nacelle yaws to 180°
  • Twist count: +0.5 turns (180°/360° = 0.5)
  • Wind shifts to West → nacelle yaws to 270°
  • Twist count: +0.75 turns (270°/360° = 0.75)
  • Wind returns to North → nacelle yaws back to 0° (via 270° → 360° → 0°)
  • Twist count: +1.0 turn (completed one full rotation)

Positive vs. Negative:

By convention:

  • Clockwise rotation (viewed from above): Positive twist
  • Counter-clockwise rotation: Negative twist

Backup: Limit Switch

Many turbines also have a physical limit switch:

  • Mechanical switch at tower base
  • Activates at maximum twist (±2.5 turns)
  • Safety backup if position tracking fails
  • Creates immediate shutdown if triggered

When Untwisting Occurs

Threshold for Automatic Untwisting:

The Controller initiates untwisting when twist reaches:

  • Typically: ±2.0 turns
  • Leaves 0.5 turn margin before limit (±2.5)

Why not wait until ±2.5?

Safety margin:

  • Wind might change during untwisting
  • Could add more twist before procedure starts
  • Better to be conservative

Typical Scenarios:

Scenario 1: Prevailing Wind Direction (Gradual)

  • Wind predominantly from one direction
  • Nacelle slowly accumulates twist in one direction
  • Takes days or weeks to reach threshold
  • Predictable, planned untwisting

Scenario 2: Shifting Wind (Variable)

  • Wind direction changes frequently
  • Twist accumulates and reduces
  • Less predictable
  • Might go weeks without needing untwisting
  • Or might need it daily in very variable wind

Scenario 3: Full Rotation Wind Pattern

  • Wind makes complete circle (rare but happens)
  • Low pressure system rotating around site
  • Adds +1.0 turn each full rotation
  • 2-3 rotations → untwisting needed

Preparation

1. Create Cable Twist

We need to accumulate cable twist to trigger the procedure.

Method A: Manual Yaw (Turbine Stopped)

If turbine is stopped:

  1. Verify turbine in STOP state
  2. Use manual yaw controls:
    • Press and hold "Yaw Right" button
    • Let nacelle rotate 1.5 full rotations (540°)
    • Release button
  3. Check cable twist indicator: Should show ~+1.5 turns

Repeat if needed to reach +2.0 turns

Method B: Simulate Wind Shifts (Turbine Running)

If turbine is running:

  1. Note current nacelle position (e.g., 90°)
  2. Change wind direction to +270° from current (e.g., to 360°)
  3. Wait for nacelle to orient (~60 seconds)
  4. Twist increased by +0.75 turns
  5. Repeat to accumulate twist

Keep changing wind direction in same rotational sense until twist reaches +2.0 turns

Method C: Direct Parameter Manipulation (If Simulator Allows)

Some simulators let you directly set cable twist:

  1. Access parameter menu
  2. Find "Cable Twist Count"
  3. Set to +2.0 turns
  4. Much faster!

2. Verify Setup

Before triggering untwisting:

Check current state:

  • Cable twist: +2.0 turns (or close)
  • Turbine: Either STOP or Production (procedure works from both)
  • Wind: Any speed (won't affect untwisting much)

Observation points ready:

  • Cable twist indicator
  • Nacelle position/orientation
  • State Machine display
  • Yaw motor indicators
  • Power output (if in production)

3. Understand What Will Happen

The Controller will:

  1. Detect twist threshold exceeded
  2. If in production: initiate cutout
  3. Rotate nacelle in opposite direction (CCW for positive twist)
  4. Reduce twist to near zero (~±0.5 turns)
  5. If conditions allow: restart production

Procedure - Cable Untwisting Sequence

Phase 1: Twist Threshold Detection

Step 1.1 - Trigger Point

When cable twist reaches threshold:

What happens:

  • Controller continuously monitors twist count
  • At +2.0 turns (or -2.0 for negative twist):
    • Threshold exceeded!
    • Untwisting procedure must be initiated

If turbine in production:

  • Cannot untwist while generating power
  • Must stop first
  • Controller decides: "Need to untwist, must stop"

If turbine already stopped:

  • Can proceed directly to untwisting
  • Simpler case

Step 1.2 - Incident Created

A new incident appears:

Incident:

  • Description: "Cable Twist Limit Approaching - Untwisting Required"
  • Or: "Automatic Cutout for Cable Untwisting"
  • Start time: Current time
  • Severity: Warning or Informational (not critical)

State Machine:

  • If in production: State changes to "Cutout for Untwisting"
  • If already stopped: State changes to "Cable Untwisting"

Record the time: When did untwisting procedure begin?

Phase 2: Cutout (If Necessary)

This phase only occurs if turbine was producing power.

Step 2.1 - Normal Shutdown Sequence

Same as Lab 2 (Normal Shutdown):

Power reduction:

  • Pitch increases from ~0° to ~45°
  • Power drops from current level to near zero
  • Takes 25-35 seconds

Electrical disconnection:

  • Open bypass contactors
  • Open generator contactor (whichever was active)
  • Power: 0 kW

Mechanical stopping:

  • Pitch continues to 90° (feathered)
  • Aerodynamic braking
  • Mechanical brake applied at low speed
  • Complete stop

Total cutout time: ~60 seconds (if was in production)

Step 2.2 - Verify Stopped

Controller checks:

  • ✓ Rotor speed: 0 RPM
  • ✓ Generator speed: 0 RPM
  • ✓ Power: 0 kW
  • ✓ Brake: Applied
  • ✓ Safe to perform nacelle rotation

If turbine was already stopped, skip to Phase 3 immediately.

Phase 3: Nacelle Rotation (Untwisting)

Now the actual untwisting happens!

Step 3.1 - Calculate Untwisting Direction

Controller logic:

Current twist: +2.0 turns (example - positive twist)

To reduce twist:

  • Must rotate in opposite direction
  • Positive twist → rotate Counter-Clockwise (CCW)
  • Negative twist → rotate Clockwise (CW)

Decision: Activate CCW yaw motor

How much rotation needed?

Target: Return to ~±0.5 turns (not exactly zero)

Why not exactly zero?

  • Wind will change during/after untwisting
  • Might as well leave in neutral position
  • ±0.5 provides buffer in both directions

Calculation:

  • Current: +2.0 turns
  • Target: +0.5 turns
  • Rotation needed: -1.5 turns (CCW)
  • In degrees: -1.5 × 360° = -540°

Step 3.2 - Begin Rotation

What happens:

Yaw motor activation:

  • Controller commands: "CCW Motor ON"
  • Motor starts
  • Nacelle begins rotating counter-clockwise
  • Speed: ~0.5°/second (standard yaw rate)

Watch for:

Yaw Motor Indicator:

  • "Yaw Left Motor: Active" (CCW direction)
  • Confirms motor running

Nacelle Position:

  • Changes continuously
  • Decreasing (if rotating CCW)
  • Example: 270° → 260° → 250° → ...

Cable Twist Count:

  • Decreases!
  • +2.0 → +1.9 → +1.8 → +1.7 → ...
  • This is what we want!

Step 3.3 - Monitor Progress

Rotation timing:

Total rotation needed: 540° (1.5 turns) Yaw speed: 0.5°/second Time required: 540° / 0.5°/sec = 1,080 seconds = 18 minutes!

Step 3.4 - Reach Target

When twist count reaches +0.5 turns:

Controller logic:

  • Detects: Twist = +0.5 (target achieved)
  • Command: "CCW Motor OFF"
  • Yaw motor stops
  • Yaw brake applies
  • Nacelle locked in new position

Final state:

  • Cable twist: +0.5 turns (safe range)
  • Nacelle: rotated 540° CCW from starting position
  • Ready for next phase

Record the time: How long did rotation take?

Phase 4: Re-orient to Wind (If Necessary)

Step 4.1 - Check Wind Alignment

After untwisting, nacelle might not be aligned with wind:

Example scenario:

  • Wind from: 180° (South)
  • Before untwisting: Nacelle was at 180° (aligned)
  • After 540° CCW rotation: Nacelle at 180° - 540° = -360° = 0° (North)
  • Misalignment: 180°! (facing opposite direction)

Controller checks:

  • Current wind direction: 180°
  • Current nacelle orientation: 0°
  • Misalignment: 180°
  • Action needed: Re-orient to wind

Step 4.2 - Orient to Wind

Standard yaw control activates:

Decision:

  • Need to rotate from 0° to 180°
  • Shortest path: +180° (CW rotation)
  • Or could go -180° (CCW) - same distance

Controller typically chooses to avoid adding twist in same direction:

  • Just untwisted CCW
  • Now rotate CW (balances out)
  • Helps keep twist near zero

Yaw sequence:

  • Activate CW motor
  • Rotate 180° (6 minutes at 0.5°/sec)
  • Stop when aligned
  • Lock yaw brake

Final alignment:

  • Nacelle: 180° (aligned with wind from South)
  • Cable twist: Still ~+0.5 (rotation canceled out previous untwisting rotation)

Wait - didn't we just add twist back?

Actually, no! Here's why:

The Math:

  • Started at: Nacelle 180°, Twist +2.0
  • After untwisting: Nacelle 0° (via CCW), Twist +0.5
  • After re-align: Nacelle 180° (via CW), Twist +0.5 (still!)

Why?

The key is: Twist is measured from ORIGINAL REFERENCE POSITION, not current position!

Think of it this way:

  • Reference position set during installation: Nacelle 0°, Twist defined as 0.0
  • If nacelle rotates to 180° and stays there: Twist +0.5 (half turn from reference)
  • If nacelle rotates 720° total (two full turns) to reach 0°: Twist +2.0 (two full turns from reference)

During untwisting:

  • We rotated nacelle to reduce cumulative rotation from reference
  • Re-orienting to wind doesn't change that cumulative count significantly (depends on where wind is)

Record the time: How long for re-orientation?

Phase 5: Resume Production (If Conditions Allow)

Step 5.1 - Check Restart Conditions

Controller evaluates if it can restart:

Conditions to check:

  • ✓ Cable twist: +0.5 (well within limits)
  • ✓ Wind speed: In range (3.5 - 25 m/s)?
  • ✓ Nacelle aligned: Misalignment < 5°?
  • ✓ Grid: Available?
  • ✓ No other faults?

If ALL conditions met:

  • Automatic restart sequence begins!
  • Same as Lab 1 (Normal Startup)

If ANY condition not met:

  • Remains stopped
  • Waits for conditions to improve
  • Example: If wind too low, waits for wind to increase

Step 5.2 - Automatic Restart

If conditions allow:

Normal cutin sequence:

  1. Brake release
  2. Acceleration to sync speed
  3. Soft-start (thyristor firing)
  4. Full connection
  5. Back in production!

Total restart time: ~90-120 seconds

Step 5.3 - Production Restored

Final state:

  • State: "Production [Small/Large]" (depending on wind)
  • Cable twist: +0.5 turns
  • Power: Normal for current wind
  • Untwisting complete!

Incident updated:

  • "Cable Twist Untwisting" → Recovered time: Current time
  • May require acknowledgment (depends on configuration)

Record the time: Total time from start of untwisting to production?

Energy Lost:

Assuming could have produced at average 500 kW:

  • Downtime: 25 minutes
  • Energy lost: 500 kW × (25/60) hr = ~208 kWh

That's substantial!

Frequency:

How often does untwisting occur?

Depends on site wind patterns:

Steady prevailing wind:

  • Wind mostly from one direction
  • Nacelle accumulates twist slowly in one direction
  • Example: +0.1 turns per day
  • Reaches +2.0 in: 20 days
  • Untwisting needed: Every 2-3 weeks

Variable multi-directional wind:

  • Wind shifts frequently
  • Nacelle yaws back and forth
  • Twist accumulates and reduces
  • Net accumulation: slower
  • Untwisting needed: Every 4-8 weeks (or longer)

Rotating wind pattern (low pressure systems):

  • Wind makes complete circles
  • Adds +1.0 turn each complete rotation
  • If 2-3 low pressure systems per week
  • Untwisting needed: Weekly

Annual Impact:

Conservative scenario: Untwist every 3 weeks

  • Untwists per year: ~17
  • Energy lost per untwist: ~208 kWh
  • Annual energy lost: ~3,500 kWh
  • Compare to annual production: ~3,000,000 kWh
  • Impact: ~0.12% (minimal!)

Worst case scenario: Untwist weekly

  • Untwists per year: ~52
  • Annual energy lost: ~10,800 kWh
  • Impact: ~0.36% (still small)

The benefit of cable method still outweighs the loss:

  • Slip rings would have continuous electrical losses
  • Estimated: 0.5-1% of production constantly
  • Plus maintenance costs and reliability issues
  • Cable method is still better overall!

Observations and Questions

Things to Notice:

1. Slow rotation speed:

Untwisting at 0.5°/sec seems very slow (18 minutes for 1.5 turns!)

Why so slow?

  • Reduces gyroscopic forces (blades stopped, but gearbox has inertia)
  • Minimizes cable stress during untwisting
  • Safer, gentler on equipment
  • Not urgent (no safety issue)

2. Asymmetric behavior:

Positive twist (+2.0):

  • Untwist by rotating CCW
  • Reduces twist to +0.5

Negative twist (-2.0):

  • Untwist by rotating CW
  • Reduces twist to -0.5

Why not return to exactly 0.0?

  • Provides buffer in both directions
  • Next wind shift might add twist in either direction
  • ±0.5 is safe, neutral starting point

3. Production interruption unavoidable:

Cannot untwist while producing:

  • Yawing changes nacelle orientation
  • Would change wind alignment
  • Power output would fluctuate wildly
  • Better to stop, untwist, restart cleanly

4. Automatic restart (usually):

After untwisting, typically restarts automatically:

  • Unless wind out of range
  • Unless other faults present
  • Minimizes human intervention
  • Good automation design!

  • Note time: T_start

Advanced Topic: Alternative Twist Management Strategies

Current Strategy: Reactive Untwisting

Wait until threshold (±2.0) → Stop → Untwist → Restart

Advantages:

  • Simple logic
  • Proven reliable
  • Maximizes production time

Disadvantages:

  • Creates dedicated downtime
  • Not optimal for energy production

Alternative 1: Opportunistic Untwisting

Idea:

  • Every time turbine stops for any reason (low wind, etc.)
  • Check twist count
  • If > ±1.0 turn, untwist while already stopped
  • No additional downtime!

Logic:

IF (turbine stopped) AND (twist > +1.0 OR twist < -1.0) THEN

  Perform untwisting

  Return twist to ±0.5

END IF

Benefits:

  • Reduces need for dedicated untwisting stops
  • Lower annual energy loss
  • Keeps twist closer to zero on average

Challenges:

  • More complex control logic
  • Might untwist unnecessarily (if would have restarted soon)
  • Need to balance: time stopped vs. twist level

Alternative 2: Predictive Untwisting

Idea:

  • Analyze wind forecast
  • Predict when low-wind period coming
  • Perform untwisting during predicted low-wind
  • Minimize high-wind downtime

Logic:

IF (forecast shows low wind in next 6 hours) AND (twist > ±1.5) THEN

  Schedule untwisting for predicted low-wind period

END IF

Benefits:

  • Optimizes timing for minimum production loss
  • Very sophisticated

Challenges:

  • Requires accurate wind forecasting
  • Complex scheduling logic
  • Forecast might be wrong

Alternative 3: Continuous Bias Correction

Idea:

  • Identify prevailing wind direction
  • Apply small continuous CCW/CW bias during normal yawing
  • Gradually work twist back toward zero
  • Never need dedicated untwisting!

How it works:

  • Wind shifts from 180° to 185°
  • Normal yaw: turn 5° CW
  • Biased yaw: turn 6° CW (overshoot slightly)
  • Accumulates twist in beneficial direction
  • Over many yaw movements, corrects twist

Benefits:

  • No dedicated downtime
  • Completely transparent to production

Challenges:

  • Very complex control logic
  • Requires careful tuning
  • Slightly sub-optimal wind alignment at times
  • Not widely used (too complex for benefit)

Why Current Strategy Dominates:

Despite alternatives, most turbines use reactive untwisting:

  • ✓ Simple, robust logic
  • ✓ Proven over decades
  • ✓ Energy loss is small (<0.5% annual)
  • ✓ No forecasting required
  • ✓ Easy to understand and maintain

The small efficiency gain from alternatives doesn't justify the complexity!

Common Issues and Troubleshooting

Issue 1: "Untwisting Triggered Too Frequently"

Symptom:

  • Untwisting procedure every few days
  • Excessive production loss
  • Cable twist seems to accumulate very quickly

Possible causes:

  • Site has very variable wind direction
  • Low-pressure systems causing rotation
  • Twist tracking error (accumulating incorrectly)
  • Threshold set too conservatively (too low)

Diagnosis:

  • Monitor nacelle position over several days
  • Plot: Nacelle orientation vs. time
  • Calculate: actual twist accumulation rate
  • Check: Is tracking correct?

Solution:

  • If site wind truly variable: normal, unavoidable
  • If tracking error: recalibrate position sensor
  • If threshold too low: adjust parameter (increase to ±2.2 or ±2.3)

Issue 2: "Untwisting Doesn't Complete"

Symptom:

  • Untwisting starts
  • Nacelle rotates for a while
  • Stops before reaching target
  • Twist count still high

Possible causes:

  • Yaw motor fault (stopped working)
  • Position sensor fault (can't detect progress)
  • Timeout limit reached
  • Manual stop during procedure

Diagnosis:

  • Check yaw motor status (still running?)
  • Check nacelle position (still changing?)
  • Check for faults in incident log
  • Review what happened when rotation stopped

Solution:

  • If motor fault: needs maintenance
  • If sensor fault: needs calibration/replacement
  • If timeout: may need multiple untwisting cycles
  • If manual stop: resume untwisting manually

Issue 3: "Position Tracking Lost"

Symptom:

  • Twist count shows unusual value (e.g., +15.7 turns - impossible!)
  • Or shows 0.0 when should be higher
  • Limit switch disagrees with position tracking
  • Controller confused about twist state

Possible causes:

  • Power loss during operation (lost reference)
  • Position sensor failed/disconnected
  • Software glitch
  • Manual tampering with parameters

Diagnosis:

  • Compare: Position tracking vs. limit switch
  • Check: Recent power outages or resets?
  • Verify: Position sensor functioning?

Solution:

  • May need to manually set twist count
  • Requires physical inspection (where is nacelle actually?)
  • Reset reference position carefully
  • In extreme case: rotate to limit switch, set to ±2.5

Issue 4: "Cannot Restart After Untwisting"

Symptom:

  • Untwisting completed successfully
  • Twist now at +0.5 (good!)
  • But turbine won't restart
  • Stays stopped even with good wind

Possible causes:

  • Unacknowledged incident from untwisting
  • Wind changed to out-of-range during procedure
  • Other fault occurred during untwisting
  • Manual STOP still active

Diagnosis:

  • Check "Open Incidents" - anything needs acknowledging?
  • Check wind speed - in range (3.5-25 m/s)?
  • Check all other system status
  • Try manual START command

Solution:

  • Acknowledge any incidents
  • Verify wind in range
  • Clear any faults
  • Manual START if auto-restart failed
