Practical Lab 1: Normal Startup Sequence (Cutin)

Objective:

Understand the complete startup sequence from stopped turbine to full production. You'll learn:

  • What conditions must be met before startup
  • The step-by-step sequence the Controller follows
  • How long each phase takes
  • What you see on the Control Terminal
  • The role of each subsystem (brakes, pitch, thyristors, etc.)

Preparation

1. Launch the Simulator

Open the wind turbine simulator application.

2. Initial State Check

The turbine should be stopped:

  • Blade pitch: 90° (feathered position)
  • Brake: Applied
  • Generator speed: 0 RPM
  • Blade speed: 0 RPM
  • Power output: 0 kW

3. Set Wind Conditions

We'll start with favorable conditions for cutin with the Small Generator:

  • Wind speed: 4.5 m/s
    • Above minimum for cutin (3.5 m/s)
    • Below switching threshold to Large Generator (6.6 m/s)
    • Good, steady wind for learning

How to set wind:

  • Look for "Wind Conditions" panel
  • Set wind speed: 4.5 m/s
  • Set wind direction: 0° (or any value - we'll align automatically)

4. Check Grid Connection

Verify the electrical grid is available:

  • Main Circuit Breaker: ON (closed)
  • All three phases present: ✓
  • Voltage: ~690V on each phase
  • No grid faults indicated

5. Clear Any Previous Incidents

In the Control Terminal:

  • Go to "Open Incidents" tab
  • If any incidents are listed, check the "OK" box for each
  • This acknowledges past events
  • Controller won't start with unacknowledged incidents

6. Position Your View

Arrange the simulator windows so you can see:

  • Control Terminal (main status screen)
  • 3D visualization (if available)
  • Key parameters display
  • Incident log

You're ready!

Procedure - The Startup Sequence

Phase 1: Initiate Startup (Manual)

Step 1.1 - Press START

In the Control Terminal:

  • Locate the "START" button
  • Click it
  • Record the time (we'll track how long each phase takes)

What happens immediately:

Nothing visible yet! But the Controller is working:

Internal checks (first 2-3 seconds):

  1. Verify all incidents acknowledged ✓
  2. Check wind speed in range (3.5 - 25 m/s) ✓
  3. Check grid voltage present ✓
  4. Check temperatures normal ✓
  5. Check hydraulic pressure adequate ✓
  6. Calculate which generator to use (Small or Large?)
    • Wind is 4.5 m/s
    • Below 6.6 m/s threshold
    • Decision: Use Small Generator (6-pole)

Step 1.2 - Observe State Machine

Watch the Control Terminal display:

Operation State Machine should show:

  • Current State: Changes from "STOP" → "Testing Wind"
  • Last Event: "EStart" (Start button pressed event)

Security State Machine remains:

  • Current State: "SS0Idle" (Safe, idle state)

Phase 2: Nacelle Orientation (Automatic)

Step 2.1 - Check Cable Twist

The Controller checks cable twist count:

  • Current twist: (displayed in status area)
  • Limit: ±2.5 turns
  • Within limits? → Proceed
  • Approaching limit? → May untwist first (see Lab 2)

Observation Point: For this lab, twist should be within limits (0 to ±1.5 turns typically).

Step 2.2 - Orient to Wind

Watch these indicators:

Wind Vane:

  • Shows misalignment between nacelle and wind
  • Example: Nacelle at 180°, Wind from 210°
  • Misalignment: 30° (nacelle is 30° off)

Yaw Motors:

If misalignment > 5°:

  • Controller activates appropriate yaw motor
  • CCW motor if wind is to the left
  • CW motor if wind is to the right

What you'll see:

On the Control Terminal:

  • "Yaw Left Motor: Active" (or "Yaw Right Motor: Active")
  • Nacelle orientation value changing
  • Misalignment decreasing

Timing:

  • Yaw speed: ~0.5°/second
  • For 30° misalignment: ~60 seconds
  • Motor stops when misalignment < 5°

Step 2.3 - Yaw Complete

When alignment is good:

  • Yaw motor stops
  • Yaw brake applies
  • State Machine updates:
    • May show intermediate state
    • Proceeding toward "Waiting for Brake Release"

Record the time: How long did orientation take?

Phase 3: Brake Release and Acceleration

Step 3.1 - Pre-Release Checks

Before releasing brakes, Controller does a safety check:

Brake holding test:

  1. Ensure brake valve is closed
  2. Command pitch to -5° (negative = into wind)
  3. Wait 5 seconds
  4. Check: Is RPM still 0?
  5. Yes? → Brake is holding, safe to proceed

Why this test?

  • Verifies brake actually works
  • Before we rely on it for stopping
  • If brake failed, we'd know now (not during emergency stop!)

Step 3.2 - Release Brake

Watch the hydraulic system:

Hydraulic Pump:

  • Starts running (if pressure was low)
  • Indicator: "Hydraulic Pump: Running"

Pressure:

  • Monitor pressure gauge
  • Rises from ~75 bar to ~95 bar
  • Takes 10-20 seconds

Brake Released Sensor:

  • Changes from "Not Active" → "Active"
  • Confirms brake pads separated from disc

State Machine:

  • State: "Waiting for Brake Release" → "Accelerating to Sync Speed Small"

Record the time: When did brake release?

Step 3.3 - Acceleration Phase

Now the exciting part - the blades start to spin!

Watch these parameters:

Blade Pitch:

  • Starts at -5° (capturing wind aggressively)
  • Controller adjusts it during acceleration
  • Goal: reach ~995 RPM (just below 1000 sync) in reasonable time

Rotor Speed (Blade Speed):

  • Starts at 0 RPM
  • Gradually increases
  • Watch it climb!

Generator Speed:

  • Starts at 0 RPM
  • Increases faster than rotor (gear ratio of ~77.73)
  • Target: ~995 RPM

Observations to note:

Pitch control strategy:

  • Starts aggressive (negative pitch) for quick acceleration
  • Gradually reduces as speed builds
  • Goes slightly positive to fine-tune approach to sync speed
  • Prevents overshooting

Acceleration rate:

  • Not constant!
  • Faster at low speeds (more margin)
  • Slower near sync speed (more careful)
  • Smoother is better (less stress on drivetrain)

Step 3.4 - Ready for Connection

When generator speed reaches ~995 RPM:

  • Controller determines: close enough to sync (1000 RPM)
  • State changes: "Accelerating..." → "Thyristors Firing Small"
  • Preparing for soft-start sequence

Record the time: Total acceleration duration?

Phase 4: Soft-Start (Grid Connection)

This is the most critical and delicate phase!

Step 4.1 - Initial Thyristor Firing

What happens:

At generator speed ~995 RPM:

  1. Controller starts firing thyristors
  2. Initial firing angle: Small (30° conduction)
  3. Small current flows from grid to generator
  4. Creates weak magnetic field
  5. Gentle torque applied to generator shaft

Watch for:

Thyristor Status:

  • Indicators change to "Active"
  • One per phase (or may show all 6)

Generator Current:

  • Starts flowing (small initially)
  • Monitor current on each phase
  • Should be balanced (all three similar)

Generator Speed:

  • Begins to increase from 995 toward 1000 RPM
  • Gentle acceleration
  • Grid is "pulling" it toward synchronous speed

Smooth progression:

Phase synchronization:

  • Happens automatically through magnetic coupling
  • Beautiful physics at work!

Step 4.3 - Full Conduction Achieved

When firing angle reaches 180° (full conduction):

  • Thyristors conducting fully
  • Generator fully connected
  • Power flowing to grid steadily
  • Speed settles at ~1008 RPM (0.8% slip)

State Machine:

  • State: "Thyristors Firing Small" → "Production Small"

Step 4.4 - Bypass Contactors Close

Final step of soft-start:

Why bypass thyristors?

  • Thyristors have voltage drop (~1.5V per device)
  • At 500A: Power loss = 1.5V × 500A × 6 devices = 4.5 kW!
  • Wasted as heat in thyristors
  • Solution: short-circuit them with contactors

The process:

  1. Verify thyristors at full conduction
  2. Close bypass contactors
  3. Current shifts from thyristors to contactors
  4. Turn off thyristor gate signals
  5. Thyristors now idle (but ready for next startup)

What you see:

  • "Bypass Contactors: Closed" indicator
  • "Thyristor Status: Inactive" (gates off, but bypassed)
  • Slight increase in power (less loss in contactors vs. thyristors)

Record the time: How long was the entire soft-start?

Phase 5: Normal Production

Step 5.1 - Steady-State Operation

The turbine is now in normal production!

Check all parameters:

Mechanical:

  • Blade speed: ~13.0 RPM (for Small Generator)
  • Generator speed: ~1008 RPM
  • Blade pitch: ~0° to +2° (optimizing for wind)
  • Gearbox ratio being used: 77.73:1

Electrical:

  • Power output: ~150-200 kW (at 4.5 m/s wind)
  • Voltage: 690V per phase
  • Current: ~150A per phase (balanced)
  • Power factor: ~0.85-0.90
  • Generator: Small (6-pole configuration)

Control:

  • State: "Production Small"
  • Bypass: Connected
  • Brakes: Released
  • Yaw: Locked (brake applied)

Wind:

  • Speed: 4.5 m/s
  • Nacelle aligned (error < 5°)

Step 5.2 - Observe Automatic Control

The Controller is actively managing the turbine:

Pitch control:

  • Adjusts blade pitch continuously
  • Goal: optimize power extraction
  • At this wind speed (4.5 m/s):
    • Trying to maximize Cp
    • Pitch near 0° (optimal)
    • Power limited by available wind (not generator capacity)

Yaw control:

  • Monitors wind direction
  • If misalignment exceeds threshold (~10°):
    • Releases yaw brake
    • Activates appropriate yaw motor
    • Rotates nacelle to align
    • Locks yaw brake again

Try this: Change wind direction

  • Adjust wind direction in simulator (add 15°)
  • Watch nacelle slowly orient to new direction
  • Takes 30-60 seconds
  • Returns to alignment

Analysis - Understanding What You Saw

Let's review the complete sequence and understand WHY each step happened:

Total Startup Time Breakdown:

Typical timing:

  1. Pre-checks: 2-3 seconds
  2. Nacelle orientation: 30-90 seconds (depends on initial misalignment)
  3. Brake release: 10-20 seconds (hydraulic pressure buildup)
  4. Acceleration: 60-90 seconds (gentle ramp to sync speed)
  5. Soft-start: 5-7 seconds (thyristor firing progression)
  6. Bypass switching: 1-2 seconds

Total: 2-4 minutes typically

Why So Long?

Each delay has a purpose:

Orientation phase:

  • Slow yaw speed (0.5°/sec) reduces gyroscopic forces
  • Allows cable twist accommodation
  • Minimizes mechanical stress

Acceleration phase:

  • Gentle acceleration protects gearbox
  • Prevents shock loads on drivetrain
  • Gives time to verify everything working correctly
  • Approaches sync speed precisely

Soft-start phase:

  • Gradual thyristor firing prevents current surge
  • Allows smooth phase synchronization
  • Minimizes mechanical shock
  • Protects generator and grid

Safety Features Observed:

Multiple checkpoints:

  1. Pre-start conditions verification
  2. Brake holding test
  3. Brake release confirmation
  4. Speed monitoring during acceleration
  5. Phase synchronization during soft-start
  6. Bypass contactor verification

Abort conditions:

  • Any checkpoint fails → abort startup
  • Wind out of range → abort
  • Grid fault → abort
  • Overspeed → emergency stop
  • System protects itself automatically!

State Machine Behavior:

You observed the Operation State Machine progress through:

  1. STOP
  2. Testing Wind
  3. (Maybe Cable Untwisting if needed)
  4. Orienting Nacelle
  5. Waiting for Brake Release
  6. Accelerating to Sync Speed Small
  7. Thyristors Firing Small
  8. Production Small

Each state has:

  • Entry conditions (what must be true to enter)
  • Actions (what happens while in that state)
  • Exit conditions (when to leave this state)
  • Transitions (which state to go to next)

The Elegance:

Think about what you just witnessed:

  • Complex coordination of multiple subsystems
  • Hydraulics, electrical, mechanical all synchronized
  • Dozens of decisions made automatically
  • Safe, smooth, repeatable every time
  • All from pressing one "START" button!

This is modern control system engineering at its finest.

Observations and Questions

Things to Notice:

1. Pitch behavior during acceleration:

  • Why start at -5°?
    • Captures maximum torque for quick start
    • Gets blades moving from standstill
  • Why increase to positive pitch near sync?
    • Prevents overshooting sync speed
    • Fine control for gentle connection

2. Generator speed target:

  • Why 995 RPM instead of exactly 1000 RPM?
    • Slightly below sync is perfect
    • Thyristors can accelerate to sync smoothly
    • If already at sync, no "room" to connect smoothly
    • If above sync, would need to slow down first

3. Thyristor firing progression:

  • Why not go straight to full conduction?
    • Gradual = gentle
    • Prevents huge inrush current
    • Allows phase synchronization to happen naturally
    • Protects equipment

4. Small Generator choice:

  • Why Small (6-pole) at 4.5 m/s?
    • Better TSR match (10.1 vs. 16.2 with Large)
    • More efficient at low winds
    • Captures more energy

Common Issues and Troubleshooting

Issue 1: "Wind Speed Out of Range" - Won't Start

Symptom:

  • Press START
  • Message: "Wind too low for cutin" or "Wind too high for safe operation"
  • State remains STOP

Diagnosis:

  • Check actual wind speed
  • Below 3.5 m/s? → Too low
  • Above 25 m/s? → Too high for safety

Solution:

  • Wait for wind to enter acceptable range (3.5 - 25 m/s)
  • This is normal and correct behavior

Issue 2: "Brake Release Timeout"

Symptom:

  • Startup begins normally
  • Stops at "Waiting for Brake Release"
  • Timeout error after 30-60 seconds

Possible causes:

  • Hydraulic pressure not building
  • Brake release sensor failed
  • Hydraulic pump not running

Diagnosis:

  • Check hydraulic pressure gauge
  • Check pump status
  • Check brake sensor status

Solution:

  • Investigate hydraulic system
  • May need maintenance (real turbine)
  • In simulator: may be a fault injection (we'll cover in later labs)

Issue 3: "Generator Overspeed During Acceleration"

Symptom:

  • Acceleration proceeding normally
  • Suddenly exceeds ~1050 RPM
  • Emergency shutdown initiated

Possible causes:

  • Wind increased too much during acceleration
  • Pitch control not responding
  • Calculation error in controller

Diagnosis:

  • Check wind speed during event
  • Review pitch commands vs. actual pitch
  • Check for pitch system faults

Solution:

  • Normal response to excessive wind during startup
  • Will retry when conditions favorable

Issue 4: "Lost Grid Phase During Soft-Start"

Symptom:

  • Soft-start begins
  • Suddenly disconnects
  • Error: "Grid fault - phase loss"

Possible causes:

  • Grid actually lost a phase (utility problem)
  • Voltage sensing fault
  • Contactor failure

Diagnosis:

  • Check grid voltage on all three phases
  • If all present: sensor or connection issue
  • If one missing: utility fault

Solution:

  • Wait for grid restoration
  • Automatic restart when grid recovers (if auto-restart enabled)
