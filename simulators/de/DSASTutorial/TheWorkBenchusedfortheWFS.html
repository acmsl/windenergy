Ein Simulator entspricht der Ausführung einer bestimmten Konfiguration auf der LdP-Plattform (©ACM.

Jede Konfiguration kann eine Anzahl von:

•Verfahren:
Bei diesem Simulator handelt es sich beispielsweise um die Überwachung und Steuerung der Ausrichtung der Gondel gegenüber der Windrichtung. Eine andere ist die Steuerung der Anzahl der Windungen der Stromkabel. Eine andere ist die Steuerung der Steigung, etc.

•Inhalt:
Diese stellen die grafische Schnittstelle des Simulators dar. Sie können Prozesse enthalten. Sie verfügen über grafische Indikatoren, die auch Steuerindikatoren sein können, um die Werte bestimmter Variablen anzuzeigen oder ihre Werte zu ändern.

•Parameter:
Jeder der definierten Prozesse kann eine bestimmte Anzahl von Parametern aufweisen. Die Parameter in LdP ermöglichen es dem Benutzer, auf ihre Anzeige und Modifikation sowie ihre Registrierung zuzugreifen. (Siehe das Tutorial "Einführung in LdP".)

•Verbindungenzwischen den obigen Elementen.

•Auf den Wunschzettel:
Dies sind Sätze von grafischen Recordern der Evolution eines ausgewählten Satzes von Variablen, speziell für einen Simulator konzipiert.

(Siehe eine ausführliche Beschreibung im Tutorial "Einführung in LdP").

Diese Prozesse verhalten sich wievirtuelle Repliken von realen physischen Elementen in elektrischen Schränken, so daß sie miteinander verbunden werden können: mit an Eingangsklemmen angeschlossenen Ausgangsklemmen.

These connections, as well as the value of the parameters, can be modified in real time; that is, they can be deleted or created even while the simulation is "running." These concepts correspond to changing the connections in an electrical cabinet or certain parameters of elements in such cabinets while the simulation is running. In this way, LdP simulators behave like highly flexible "Laborarbeit."
