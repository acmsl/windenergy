'Controller State Machines' Panel

Windkraftanlage Simulator mit Active Stall und zwei Geschwindigkeiten ›› Synoptics verwendet in diesem Simulator ›› Wie Sie einen Recorder anzeigen und ein vordefiniertes Panel auswählen. ››

Die folgende Figur zeigt das Panel namens 'State Machines', das 4 Kanäle enthält.

1.Der erste 'Kanal' zeigt ein Signal, das demLetztes Ereigniserhalten durchSicherheitszustandsmaschineim Controller implementiert. Vgl.Sicherheitszustandsmaschine.

2. Der zweite 'Kanal' zeigt ein Signal, das demStromwertdie SicherheitszustandsmaschineStatus.

3. Der dritte 'Kanal' zeigt ein Signal, das demLetztes Ereigniserhalten durchBetriebszuständeim Controller implementiert. Vgl.Operation State Machine.

4. Der vierte 'Kanal' zeigt ein Signal, das demStromwertdie Betriebszustandsmaschine.

Dieses Panel ist sehr nützlich für die folgenden Aktionsprotokolle im Controller implementiert, um auf verschiedene Umstände und Vorgänge zu reagieren.
