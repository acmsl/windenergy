Panel 'RPMs + Pitch + Status Maschinen '

Windkraftanlage Simulator mit Active Stall und zwei Geschwindigkeiten ›› Synoptics verwendet in diesem Simulator ›› Wie Sie einen Logger anzeigen und ein vordefiniertes Panel auswählen. ››

Die folgende Abbildung zeigt das Panel "RPMs + Pitch + State Machines", das 6 Kanäle enthält.

1.Der erste 'Kanal' zeigt ein einziges Signal mit demDrehzahl der elektrischen Generatorwelle(in RPMs).

2. Der zweite 'Kanal' weist zwei Signale auf:

1.Signal erzeugt im Controller und verwendet alsder Sollwertfür die KlingeStellplatz.

2. Signal vom Nabensimulator, mit dem aktuellen Pechwert der Schaufeln.

3. Der dritte 'Kanal' stellt ein Signal dar, das demLetztes Ereigniserhalten durchSicherheitszustand Maschineim Controller implementiert. Vgl.Sicherheitszustandsmaschine.

4. Der vierte 'Kanal' stellt ein Signal dar, das demStromwertdie Sicherheitszustandsmaschine.

5. Der fünfte 'Kanal' zeigt ein Signal, das demLetztes Ereigniserhalten durchBetriebszuständeim Controller implementiert. Vgl.Operation State Machine.

6. Der sechste 'Kanal' zeigt ein Signal, das demStromwertdie Betriebszustandsmaschine.

Dieses Panel ist sehr nützlich für die folgendenAktionsprotokolleim Controller implementiert, um auf unterschiedliche Umstände und Vorgänge in Bezug auf die wichtigsten mechanischen Größen zu reagieren.
