Grundkomponenten

Struktur der LdP-Anwendungen ›› Grundkonzepte ››

Eine LdP-Anwendung (Simulator) wird durch eine Beschreibung in einer Konfigurationsdatei definiert.

•Jede der im Simulator verwendeten Komponenten wird angegeben.

• Die Verbindungen zwischen dem Ausgang und den Eingangssignalen jeder der Komponenten werden angegeben.

• Zusätzliche Elemente sind definiert: Parameterwerte, Hilfe, Definition von grafischen Recorder-Konfigurationen, etc.

Die "Komponenten" einer LdP-Konfiguration können von folgenden Typen sein:

Verfahren

Dieses Element kann keine, eine oder mehrere enthalten "Verfahren" Typenelemente. Jeder dieser bezieht sich auf eine speziell entwickelte DLL, um einen bestimmten Aspekt oder Teilsystem zu simulieren.

Inhalt

Dieses Element kann ein oder mehrere "Synoptische" Typenelemente enthalten. Diese Elemente beziehen sich auf DLLs, die speziell mit grafischen Indikatoren entwickelt wurden. Sie stellen die Benutzeroberfläche dar.

Verbindungen

Dieses Element enthält "Interne Verbindung" Typenelemente. Diese Elemente enthalten ein "Ausgangssignal" und ein oder mehrere "Eingangssignale".

Parameter

Dieses Element enthält keine, ein oder mehrere "Parameter"-Elemente. Jeder von ihnen hat ein zugehöriges "Ausgangssignal" mit einem Namen, der einem Prozess oder einem Synoptic zugeordnet ist. Es gibt eine Basis-Synoptische ("Parameter"), mit der Sie auf diese "Parameter" zugreifen und den zugehörigen Wert ändern können. Es wird üblicherweise verwendet, um Parameter von Algorithmen zu definieren, die in den verschiedenen "Process"- und "Synoptischen" Elementen implementiert sind.

Auf den Wunschzettel

(Aufzeichnungen) Dieses Element enthält einen Satz von "Panel" Typenelemente, die jeweils den Inhalt und das Format von " definierenAufzeichnungen,", durch die der Satz der dargestellten Signale und die Form der Darstellung definiert sind.

Funktionen

Elemente, die keine, eine oder mehrere " enthaltenFunktion" Typenelemente. Jedes dieser Elemente implementiert ein "Formel": Jede Formel hat ein zugehöriges Ausgangssignal und einen Satz von Eingangssignalen entsprechend den verwendeten Variablen.
