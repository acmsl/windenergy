Einleitung


LdPist eine Echtzeit-Simulator-Entwicklungs- und Ausführungsumgebung von Automated Computing Machinery S.L. (www.acm-sl.com) (nachfolgend ACM SL genannt).


Seine Hauptmerkmale sind:

•Es ist eine Windows-Desktop-Anwendung.

•Es isauf der Grundlage der umfangreichen Verwendung von Windows ActiveX Komponenten und DLLs. Diese Komponenten können in verschiedenen Programmierumgebungen (MS Visual Studio VC++, Visual Basic, etc.) entwickelt werden.

•Jeder Simulator ist in einer Konfigurationsdatei beschrieben.

•Die Verbindungen der Komponenten in der Konfigurationsdatei können jederzeit bearbeitet werden, auch während die Simulation läuft. Die Verbindungen deuten das Konzept der Verbindung zwischen elektrischen oder elektronischen Komponenten an: die Ausgänge einiger können mit den Eingängen anderer verbunden werden. Sowohl Ausgangs- als auch Eingangsanschlüsse werden in LdP als "Signale" bezeichnet. Signalnamen haben eine Dreifeld-Nomenklatur: "In den Warenkorb"."Prozess miteiner Komponente"."Vorname." Zum Beispiel: "Controller.Control.PitchOut" bezieht sich auf einen Ausgang namens "PitchOut" aus dem "Control"-Prozess der "Controller"-Komponente, wie in der Konfigurationsdatei angegeben.

•Die grundlegenden Funktionalitäten für jeden Simulator ohne zusätzliche Programmierung sind:

o Echtzeit-Aufzeichnung von Änderungen in jedem der Signale (Datenverarbeitung) in standardisierten Datenbankdateien.

oVerfügbarkeit von Aufzeichnungsformularen (Aufzeichnungen or Auf den Wunschzettel) durch die Signalentwicklungen in Echtzeit angezeigt werden.

oVerbindungen und Parameter können während der Ausführung der Simulation geändert werden, ohne dass diese neu gestartet werden muss.
