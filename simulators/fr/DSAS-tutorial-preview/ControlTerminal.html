Terminal de Contrôle

Description du Simulateur ›› Simulateurs de sous-systèmes dans l'éolienne ››

Chaque fabricant d'éoliennes fournit un dispositif appelé «terminal de contrôle» que l'opérateur doit utiliser pour accéder au contrôleur de l'éolienne.

Il y en a plusieurs types, des terminaux robustes à usage spécial avec seulement l'affichage de base et les fonctions de clavier aux applications fonctionnant sur des PC robustes.

Functions

Le Terminal de Contrôle est l'outil de base utilisé par les Opérateurs pour:

•Connaître la situation exacte de l'éolienne.

•Accès aux variables internes de l'éolienne, y compris celles qui ne sont pas accessibles par d'autres moyens, comme la connexion SCADA.

•Accès aux données historiques (production, énergie, incidences, etc.)

•Accès aux paramètres utilisés pour affiner le comportement de l'éolienne sur un site spécifique.

Le terminal de contrôle est également utilisé par l'application interne dans le contrôleur de l'éolienne pour forcer la reconnaissance de certains types d'incidences. De cette façon, le contrôleur peut tenir un journal de tous les incidents qui se produisent à l'éolienne, quand ils ont été signalés et quand ils ont été reconnus par l'operateur.

Comme le nombre d'options accessibles via ce terminal est important, ces options ont été regroupées sous la forme d'un arbre. Cette disposition des options de visualisation et de commande n'est pas très didactique; par conséquent, dans ce simulateur, on utilise un synoptique spécial  où les valeurs des variables les plus significatives et didactiques sont présentées directament, ainsi que les fonctions de contrôle les plus utilisées sont facilement accessibles et didactiques.
