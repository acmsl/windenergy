Enregistreurs a bande

Description du Simulateur ›› Synoptiques ››

Un synoptique Enregistreur à bande (StripRecorder) présente l'évolution d'un ensemble de signaux, tout comme un enregistreur à bande de type papier normal. Plusieurs de ces enregistreurs peuvent être ouverts simultanément, chacun associé à un ensemble de signaux différents.

Les concepts de ce synoptique sont:

1.Bande : Semblable à une bande dans un enregistreur papier avec plusieurs stylos. Le temps passé progresse vers la gauche, avec l'instant courant toujours dans la bordure vers la droite.

2.Chaque bande peut présenter plus d'un signal.
Chaque signal a une couleur associée et possède une légende pour cette association.
Chaque bande a sa propre hauteur mais tous partagent la même largeur.
Comme il y a une seule échelle, tous les signaux présentés dans un enregistreur doivent partager les valeurs maximum et minimum.
Chaque bande peut présenter un seul type de signal: analogique ou booléen.
Dans l'option booléen, chaque signal est présenté légèrement déplacé, de sorte que si deux signaux numériques ont la même valeur pendant une partie du temps, ils ne se cachent pas.

3.Les bandes sont présentées groupées en panneaux: chaque panneau a un nom associé et une description.

4.Chaque pixel dans la direction horizontale est associé à un intervalle de temps. Cet intervalle peut être changé avec le bouton "Temps par pixel". Ce bouton présente un combobox avec les options possibles pour cet intervalle, entre 0,2 seconde / pixel et 5 secondes / pixel.

5.Vous pouvez obtenir une image, qui est une copie du contenu à ce moment de ce synoptique: utilisez le bouton 'Copie'. Cette image est présentée dans un type de synoptique spécifique, de type 'Hardcopy', qui possède des fonctionnalités d'exploration temporelle. Voir description de le synoptique type Hardcopy ici.

6.Le bouton "Panneaux prédéfinis" possède une liste déroulante avec tous les panneaux disponibles.
