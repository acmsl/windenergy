The Controller emulator controls the behavior of the Wind Turbine with a set of algorithms coordinated by two "State Machines": this is a way of specifying the behavior that can be represented graphically (see Operation SM and STOPSequencesSM ).

The reading of this diagram can be summarized as follows:

At any moment the state machine is in a one and only one state (Squares or circles). That state changes upon the reception of an event (directed lines joining two states) and after that the interpreter of the state machine execute the specified "action". The event name and the associated action is written near the middle of the event line.

Those diagrams are very good for understanding the logic of the algorithms. Nevertheless it is also very important to know (to see) how is the evolution of the state transitions for given operation. In order to have that representation, you can use any panel of the StripRecorders that present the moments when the events happen and how these events affect the changes in the state of the corresponding state machine.
