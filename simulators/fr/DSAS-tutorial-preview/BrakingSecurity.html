Le simulateur de système de freinage hydraulique utilise les paramètres suivants:


Paramètre

Use

NacelleBrake.PumpCaudal

Set the pump caudal as a percent respect to the total volume in the circuit

NacelleBrake.LeakageBrakeHydrCircuit

Set the percent of loss of pressure inside the hydraulic circuit due to any reason: valve leakage, connections leakage, pump leakage, etc. In percent.


Le simulateur de system de sécurité pour la survitesse utilise les paramètres suivants:

Paramètre

Use

Nacelle.GeneratorSpeedVCU

Limite de VCU. Si le rpms du générateur dépasse cette limite, une séquence d'arrêt spécifique est démarrée.

Nacelle.RotorSpeedforHCU

Limite HCU.  Si le rpms du générateur dépasse cette limite, une séquence d'arrêt spécifique est démarrée.
