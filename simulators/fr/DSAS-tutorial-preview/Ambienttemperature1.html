Capteurs bimétalliques

Introduction ›› Description de l'éolienne ›› Description des composants d'une éolienne ›› Capteurs de température ››

Les capteurs de température à bande bimétallique sont formées par deux bandes de matériaux électriquement conducteurs mais avec des différents coefficients de dilatation thermique, qui sont soudées ensemble de manière rigide. Lorsque la température change, les bandes ont tendance à se courber, comme le montre la figure suivante.

Ils sont très robustes et sont normalement utilisés pour détecter que la température de certains composants atteint une valeur fixe: quand elle dépasse, le circuit change d'état (ouverture normale).
