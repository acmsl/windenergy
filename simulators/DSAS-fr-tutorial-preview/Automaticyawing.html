This mode is active when you press the "START" button in the Control Terminal and there is enough wind (parameter "Controller.WindMinForAutomaticYawing" - typically 1.5 m/s-) then the Controller start the yawing process using the shortest path. That happens after waiting an amount of time (fixed) to check that the wind direction is stable.


The the MaxCablesTurns limit applies, so that if in the approach path the number of the turns of the power cables gets above that limit, then the UnTurnCables algorithm applies till the tolerance (+ or - 0.1 turns). After reaching that turns value the automatic yawing process continues.
