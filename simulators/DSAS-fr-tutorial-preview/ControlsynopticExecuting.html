Synoptique de Contrôle de l'exécution ("Exécution")

Description du Simulateur ›› Synoptiques ›› Synoptiques communs du banc de travail ››

C'est le synoptique de contrôle de base de la configuration.


•Le bouton 'Quitter' vous permet de quitter le programme.


•Le bouton 'Courir' permet d'exécuter la simulation une première fois après l'exécution du programme. Après avoir appuyé sur ce bouton, le titre change pour 'Arrêter'.


•Si vous cliquez sur le bouton 'Arrêter', le programme arrête l'exécution de la simulation, et le bouton change à 'Continuer'.


•Si vous cliquez sur le bouton 'Continuer', le programme poursuit l'exécution de la simulation et le bouton change à 'Arrêter'.


•Le bouton 'Synoptique' affiche une liste des synoptiques que vous pouvez présenter à l'écran. Ceux qui sont spécifiques à la configuration en cours d'exécution contiennent une case à cocher avec laquelle vous pouvez les rendre visibles ou non.


•Le bouton 'Tutoriel' montre une liste des tutoriels associés à ce simulateur.

•Le bouton 'Messages' présente un formulaire avec des messages spécifiques que l'application peut envoyer. Ces messages dépendent de la configuration.

•Le bouton 'Information Application' présente des informations sur les composants utilisés dans la configuration.

La seule option du menu 'Information de licence' présente les données de licence actuelles pour cette configuration.

la valeur dans LicenseID contient la référence de licence.
