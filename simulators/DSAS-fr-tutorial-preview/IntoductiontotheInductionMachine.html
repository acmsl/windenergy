Couple mécanique vs vitesse de rotation

Le comportement d'une machine asynchrone est représenté sur le graphique suivant, où le couple mécanique (appliqué ou opposé) dans l'axe du rotor est représenté en fonction de la vitesse de rotation dudit axe.

Sur ce graphique, les ordonnées sont représentées avec une valeur positive lorsque le couple mécanique freine, c'est-à-dire lorsqu'il fonctionne en moteur.

La vitesse de rotacion où le couple est 0 correspond à la transition entre le moteur et le générateur,  est connue comme vitesse de synchronisme. La vitesse de synchronisme est proportionnelle à la fréquence du courant qui traverse les enroulements du stator et est inversement proportionnelle au nombre de paires de pôles magnétiques créées dans l'entrefer. 

Vsynch = (120 * Fréquence) / NombrePôles

Le point de fonctionnement en tant que moteur est au-dessous de la vitesse de synchronisme, (point A), au-dessus il fonctione comme générateur (Point B). On utilise le concept de «glissement» pour décrire le point de fonctionnement d'une machine asynchrone. 

Le glissement (slip en anglais) est défini comme le rapport entre la vitesse de rotation et la vitesse synchrone:

Slip = ( 1 - Vitesse du axe / Vitesse de synchronisme)

Selon cette définition, nous pouvons avoir les cas suivants:

Slip = 1

 L'axe est arrêté

Slip = 0

L'axe est à vitesse de synchronisme

slip > 0

La machine agit en tant que générateur. Aussi connu sous le nom de "mode supersynchrone"

Slip < 0

La machine agit comme moteur. Aussi connu sous le nom de "mode subsynchrone".
