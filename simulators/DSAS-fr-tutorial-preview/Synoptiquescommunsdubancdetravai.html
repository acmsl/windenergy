Types de synoptique

Description du Simulateur ›› Synoptiques ››

Dans le framework LdP, il existe trois types de synoptiques:

•Synoptiques communes à toutes les configurations, qui permet accéder aux fonctions de base, telles que l'exécution / l'arrêt / la poursuite de la simulation; l'édition de la valeur des paramètres utilisés dans les processus; l'édition des connexions entre les signaux.

•Enregistreurs a bande: qui contient la représentation graphique de l'évolution dans le temps de certains signaux.

•Synoptiques spécifiques de la configuration exécutée.
