Broken valve

Exercises recommendés ›› Surveillance du circuit hydraulique ››

We can simulate that the valve is broken so that it can not block the flow of fluid so the pressure in the circuit can not grow, simply using the capability of the digital widgets in LdP that allows two behaviors:

•To present the value associated with its input or not.

•To "transmit" to its output the value of at its input or not.

See "Properties of LdP specific widgets" in the "Introduction to LdP" tutorial.

Do as follows:

•Set the Wind Turbine into production state.

•In the SynopticDriveTrain select the "Hardbrake" widget (click on it with the mouse)

•Press "F6" key: the widget will change its mode to "Forcing" , indicated by a red line surrounding it. (Pressing again "F6" will return to the "Following input" mode; keep it in Forcing mode.)

•Press the "Hardbrake" button so the active value is On, This is indicated as  

•In very few moments, the pressure in the hydraulic circuit will drop and, as consequence, the Controller will initiate a shutdown of the Wind Turbine.

•In the "Opened incidences" tab will register a message type 14 with "Bypass or Thyristor on and brake not released.

•Shortly after there will be another message (type 18) with "Pumping time too long".


This last message has to do with the value of the "Parameter.NacelleBrake.HydrPumpMaxRunTime".

To "repair" the "broken" valve just press "F6" again on the "Hardbrake" and acknowledge the two opened incidences: the Controller will initiate a cutin process.
