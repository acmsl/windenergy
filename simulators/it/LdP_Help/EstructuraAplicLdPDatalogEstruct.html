Struttura dei database di log

Struttura delle applicazioni LdP ›› Registrazione del valore di segnale (datalogging) ››

La struttura dei database utilizzati per registrare l'evoluzione dei segnali in una simulazione è la seguente:

•Sono contenuti in un unico file creato con il motore del database SQLite 3.6.

• Làè una tabella per ogni segnale, se "output" o "input".

•Ogni tabella contiene due campi che dipendono dal tipo di segnale (analogico o digitale). Uno di questi campi ("Data") è comune. Vedi i seguenti dettagli:

I valori nel "Data" campo corrispondono alla data e all'ora con risoluzione milliseconda. La formula di conversione è la seguente:

Instant = (DateFieldValue)/86400000 - 693593
