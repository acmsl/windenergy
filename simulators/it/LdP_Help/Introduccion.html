Introduzione


LdPè un ambiente di sviluppo e esecuzione simulatore in tempo reale sviluppato da Automated Computing Machinery S.L. (www.acm-sl.com) (di seguito denominata ACM SL).


Le sue caratteristiche principali sono:

•È un'applicazione desktop di Windows.

• isin base all'uso esteso di componenti e DLL Windows ActiveX. Questi componenti possono essere sviluppati in vari ambienti di programmazione (MS Visual Studio VC++, Visual Basic, Delphi, ecc.).

•Ogni Simulatore è descritto in un file di configurazione.

•Le connessioni dei componenti nel file di configurazione possono essere modificate in qualsiasi momento, anche mentre la simulazione è in esecuzione. Le connessioni imitano il concetto di connessione tra componenti elettrici o elettronici: le uscite di alcuni possono essere collegate agli input di altri. Entrambe le connessioni di output e input sono chiamate "segnali" in LdP. I nomi dei segnali hanno una nomenclatura a tre campi: "Nome del componente"."Processoconcomponente"."Nome corretto. Per esempio: "Controller.Control.PitchOut" si riferisce a un output chiamato "PitchOut" dal processo "Control" del componente "Controller", come dichiarato nel file di configurazione.

•Le funzionalità di base disponibili per ogni Simulatore senza programmazione aggiuntiva sono:

registrazione oReal-time di modifiche in ciascuno dei segnali (Registrazione dati) nei file di database standardizzati.

oDisponibilità di moduli di registrazione (Registratori or Registratori di strisce) attraverso i quali le evoluzioni del segnale vengono visualizzate in tempo reale.

oLe connessioni e i parametri possono essere modificati durante l'esecuzione della simulazione, senza la necessità di riavviarla.
