Esportazione dei dati in Excel

Struttura delle applicazioni LdP ›› Registrazione del valore di segnale (datalogging) ››

L'applicazione desktop SQLiteAdministrator (http://sqliteadmin.orbmu2k.de/) ha l'opzione di esportare i dati del file SQlite in Excel.


Il plugin Firefox "SQLite Manager" consente anche di esportare i risultati di una query a un file CSV (Comma Individuald Values).

Questi file possono essere importati nelle cartelle di lavoro di Excel. Le ultime versioni di Excel includono un formato che visualizza correttamente il formato della data con risoluzione di millisecondo.
