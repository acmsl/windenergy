File di registro (Registrazione dati) sono memorizzati nella directory "C:\WFS_Datalog\name_of_the_simulator\" e il loro nome riflette il tempo in cui la sessione di simulazione è iniziata.

I file creati con SQlite possono essere gestiti da un gran numero di applicazioni, tra cui molte che sono open source. Per esempio, il "SQLite Manager" plug-in per ilFirefoxbrowser consente di aprire e modificare questi file. Vedi la figura seguente.
