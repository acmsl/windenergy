Componentes del Simulador

Descripción del Simulador de Parque Eolico ››

Este simulador contiene un sinóptico principal, que se muestra en la figura siguiente.

Fig 1

En él se incluyen conjuntos de indicadores gráficos y botones interactivos que presentan diferentes datos al usuario, y le permiten interactuar con el simulador. Estos conjuntos gráficos se describen el los epígrafes que siguen.

Adicionalmente, el simulador, al ser una aplicación ejecutada sobre LdP (Ver el tutorial "Introducción a LdP"), incluye el sinóptico de control de ejecución, como se muestra en la figura siguiente.

Fig 2.

Además, la configuración de este simulador incluye un conjunto predefinido de "Registradores" ("Sinópticos" -> "Registradores") diseñados para facilitar la observación de diferentes variables del parque eólico en el simulador.
