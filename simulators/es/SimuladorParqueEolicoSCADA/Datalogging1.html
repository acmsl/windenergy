Registro de datos

Este simulador, al ser una aplicación LdP, va guardando en memoria la evolución de las diferentes señales que se intercambian entre sus sub-sistemas.

Al salir de ella se pregunta si se desea guardar estas evoluciones en disco. Ver figura.

Si la respuesta es "Aceptar", se crea un fichero de base de datos en el directorio "c:\WFS_Datalog\Simulador de Parque Eolico\aa-nn-dd-hh-mm-ss.sqlite" donde "aa-mm-dd-hh-mm-ss" corresponde a la fecha en la que se comenzó la sesión.

"aa" es el año, pe, "16" para "2016"; "nn", es el mes, "dd", es el dia; "hh", es la hora; "mm", es el minuto: y "ss" es el segundo, del comienzo.
