Paneles predefinidos para los Registradores

Descripción del Simulador del Aerogenerador DFIG ›› Sinópticos ››

Este Simulador incluye un conjunto de Paneles predefinidos, diseñados específicamente para observar la evolución de diferentes conjuntos de señales, cada uno para experimentos específicos.

Estos diseños afectan a:

  • El conjunto de señales que se presentan en un mismo Registro.
    Cada Registro en un Panel puede presentar mas de una señal, lo que facilita la comparación de la evolución de las mismas.
  • El color asociado a cada señal.
  • El rango de valores de cada Registro.
    El eje vertical (ordenadas) puede tener un rango de valores que no corresponda con el rango de valores de la seña. Esto permite definir vistas de zoom.
  • El orden de los Registros en el Panel.
  • La altura de cada Registro.
  • El color de fondo del Panel.
