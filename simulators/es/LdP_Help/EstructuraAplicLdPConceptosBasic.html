Conceptos básicos

Estructura de las aplicaciones LdP ››


La estructura de LdP está diseñada para facilitar el diseño de Simuladores: un concepto básico es el de utilizar un paradigma muy intuitivo y aceptado: un armario eléctrico o dispositivo electrónico. Estos equipos tienen "componentes" (eléctrico o electrónicos) independientes e interconectados. Las conexiones entre estos componentes se realiza mediante el simil de cables eléctricos que conectan "señales de salida" con "señales de entrada". Una señal de salida se puede conectar a una o más señal de entrada, pero no con otra señal de salida.

Como resultado estas conexiones son representables con un esquema tipo eléctrico.

LdP dispone de "herramientas" para la observación de estas conexiones y para cambiarlas, de forma que sus funcionalidades coinciden con los de un "banco de trabajo o de laboratorio", donde se dispone de fuentes de alimentación, voltímetros, amperímetros, osciloscopios, etc.

Adicionalmente LdP provee registro en una base de datos de todos los cambios que se producen en las señales del Simulador, con resolución de 1 milisegundo.
