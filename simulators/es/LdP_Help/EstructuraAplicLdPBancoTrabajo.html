El LdP como banco de trabajo

Estructura de las aplicaciones LdP ›› Conceptos básicos ››

Como se ha indicado en Conceptos básicos un simulador desarrollado en LdP se puede representar como un esquema eléctrico en el que existen diferentes bloques que se asume realizan determinadas operaciones (partes del simulador) que reciben un conjunto de señales y que generan otras señales que, se asume, servirán para otros bloques.

Estos bloques están interconectados entre sí mediante "conexiones", equivalente a cables físicos en un cuadro eléctrico. La siguiente figura ilustra este concepto.


Adicionalmente, el LdP dispone de mecanismos que le permiten funcionar como un "banco de pruebas" o "banco de trabajo". La idea es la de facilitar el cambio de las condiciones en las que se ejecuta el simulador y observar las respuestas del mismo a esos cambios. A este efecto, se asume que cada simulador dispone de los adecuados sinópticos, adaptados a las necesidades de simulación del equipo o sistema que se quiere simular. A continuación se presentan algunos ejemplos:

Subsistema de Circuito Hidráulico de Frenos.

Indicador de presión en un circuito hidráulico.

Indicador de vectores de flujo magnético en una máquina de inducción.

Valor actual de una función de varios parámetros.

Valor de dos señales (Potencias mecánica y eléctrica) sobre mapa de posibles areas de funcionamiento.

Punto de funcionamiento y pendiente asociada.


Además LdP dispone de indicadores / controles que son elementos gráficos que se usan para presentar valores de señales y también para forzar los valores de otras señales. Estos indicadores, disponibles para los desarrolladores de sinópticos compatibles con LdP, han sido diseñados para minimizar el espacio requerido en pantalla para diseñar una Interface de Usuario que sea a la vez completa y no sea abrumadora.

Estos componentes de LdP se describen en la sección siguiente y su principal característica es que pueden ser utilizados tanto para indicar el valor de una señal como para forzar dicho valor de forma manual.

Adicionalmente, LdP dispone de "Registradores" para visualizar la evolución de cambios de determinadas señales elegidas como significativas, así como un editor de conexiones, (que permite simular el concepto de cable cortado) y otro editor de parámetros, valores característicos de unidades de simulación dentro del simulador general.
