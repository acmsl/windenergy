Cada Tutorial incluye una serie de  Paneles consistentes en Registradores, que el autor estima adecuados para la configuración. Esta serie está agrupada debajo del (único) elemento "StripRecorders".

Ejemplo:

<StripRecorderPanels backColor="1" borderColor="0">

<Panel name="Pitch, Potencias, Freno, RPMs, Viento" description="Panel general">

      <Recorder type="A" name="Pitch" maxValue="+55" minValue="-5" height="120">

        <Signal type="A" name="Controller.Control.PitchOut" color="0,0,255" />

        <Signal type="A" name="Nacelle.DriveTrain.PitchNacelleOut" color="0,128,0"/>

        <MarkLine value="90.0" label=" 90" alphaValue="130" color="0,0,0"/>

        <MarkLine value="45.0" label=" 45" alphaValue="130"/>

        <MarkLine value="-5.0" label="-5" alphaValue="130"/>

        <MarkLine value="0.0" label="0" alphaValue="130"/>

        <MarkLine value="30.0" label=" 30" alphaValue="130"/>

        <MarkLine value="20.0" label=" 20" alphaValue="130"/>

        <MarkLine value="10.0" label=" 10" alphaValue="130"/>

      </Recorder>


      <Recorder type="A" name="Potencias" maxValue="1700000" minValue="-10" height="120">

<Signal type="A" name="Nacelle.DFIGB2B.GridActivePower" color="0,128,0" />

<Signal type="A" name="Nacelle.DriveTrain.ActualWindPowerOut"/>

<MarkLine value="0" label="0" alphaValue="130"/>

<MarkLine value="500000" label="500kW" alphaValue="130"/>

<MarkLine value="1000000" label="1MW" alphaValue="130"/>

<MarkLine value="1500000" label="1.5MW" alphaValue="130"/>

      </Recorder>


      <Recorder type="D" name="Frenos" height="60">

<Signal type="D" name="Nacelle.Braking.BrakeReleasedOut"/>

      </Recorder>


</Panel>

</StripRecorderPanels>

Descripción de Elementos asociados a StripRecorders

StripRecorders

 Este elemento tiene dos "propiedades" o "atributos"

Propiedad

Descripción

backColor

Esta propiedad determina el color de fondo de los Paneles. Las formas posibles de especificar este color son las siguientes:

="0" : color negro de fondo.

="1" : color blanco de fondo.

="R,G,B" , donde R, G y B son valores enteros entre 0 y 255.

Ejemplo: con "200,200,200" se obtiene el siguiente color de fondo.

borderColor

="0" (Uso futuro).

Panel

Este elemento tiene dos propiedades "name" y "description", ambas texto. Cada panel corresponde con un sinóptico. Puede contener uno o más elementos "Recorder".

Recorder

Este elemento puede contener uno o más elementos "Signal" y cero, uno o más elementos "MarkLine". Tiene las siguientes propiedades:

Propiedad

Descripción

type

Obligatorio. Puede ser "A" si se quiere representar señales analógicas, o "D" si son digitales.

name

Obligatorio. Sirve para la identificación.

maxValue

Obligatorio. Valor superior del eje vertical de valores.

minValue

Obligatorio. Valor inferior del eje vertical de valores.

height

Obligatorio. Altura del Recorder en pixels.

scaleMode

Opcional. Los valores pueden ser "lin" o "log". El valor por defecto es "lin.

Si "lin", la escala de valores de la señal es lineal.

Si "log", la escala de valores de la señal es logaritmica.

Signal

Este elemento especifica una de las señales que se representarán en el elemento "Recorder" dentro del cual está definida. Se puede elegir el color.

Propiedad

Descripción

type

Obligatorio. Puede ser "A" si se quiere representar señales analógicas, o "D" si son digitales.

name

Obligatorio. Debe corresponder con el nombre de una "signal" válida. Ver Sinóptico para edición de Señales y Conexiones .

color

Obligatorio. ="R,G,B" , donde R, G y B son valores enteros entre 0 y 255.

MarkLine

Este elemento presenta una línea horizontal correspondiente a un valor posible de las señales que se representan en el elemento "Recorder" en donde está definido. Se puede cambiar el color y la transparencia. El texto asociado que se presenta a la derecha del eje de ordenadas

Propiedad

Descripción

value

Obligatorio. Valor asociado. Ejemplos: "10.0", "-15.0" , "1e-4", "-2e+8".

label

Obligatorio. Texto que se presenta a la derecha del eje de ordenadas.

color

Obligatorio. ="R,G,B" , donde R, G y B son valores enteros entre 0 y 255.

alphaValue

Obligatorio. valor entre 0 y 255 correspondiente al grado de transparencia de la línea horizontal dibujada. 0 es totalmente transparente. 255 es no transparente.
